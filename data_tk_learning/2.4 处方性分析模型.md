# 2.4 处方性分析模型 —— "应该怎么做"

> 处方性分析是数据分析的最高层次——不仅告诉你发生了什么、为什么、将发生什么，还直接告诉你应该怎么做，甚至给出不同选择的预期结果。学完这章，你能从数据分析师变成"决策参谋"。

**学完这章你能干啥？**
- 能用情景分析模拟不同决策的结果
- 能设计 A/B 测试验证方案效果
- 能用优化分析找到最优方案
- 能输出清晰的决策建议和追踪计划

---

## 一、什么是处方性分析？

### 1.1 用生活例子理解

**用生活例子理解**：

就像医生开处方——不仅告诉你"血压偏高"（描述性）、"因为饮食不当"（诊断性）、"不控制会中风"（预测性），还直接给你开药方："每天吃这个药，少吃盐，多运动"（处方性）。

**代码示例**：

```python
# 描述性分析：只知道"发生了什么"
血压 = 150
print(f"血压偏高：{血压}")

# 诊断性分析：知道"为什么"
原因 = "饮食不当，盐摄入过多"
print(f"原因：{原因}")

# 预测性分析：知道"将怎样"
风险预测 = "不控制可能导致中风"
print(f"风险预测：{风险预测}")

# 处方性分析：知道"该怎么做"
处方 = {
    "药物": "每天服用降压药",
    "饮食": "每日盐摄入<5克",
    "运动": "每周运动150分钟",
    "预期效果": "3个月后血压降至正常范围"
}
print("处方建议：")
for 项目, 建议 in 处方.items():
    print(f"• {项目}：{建议}")
```

**专业术语**：

处方性分析（Prescriptive Analytics）是数据分析的**最高层次**，不仅告诉你发生了什么、为什么、将发生什么，还直接告诉你**应该怎么做**，甚至给出不同选择的预期结果。

### 1.2 分析四层次对比

| 层次 | 核心问题 | 输出形式 | 生活类比 | 医疗场景对应 |
|------|----------|----------|----------|-------------|
| 描述性 | 发生了什么？ | 报表、仪表盘 | 体检报告 | 症状描述 |
| 诊断性 | 为什么发生？ | 根因分析报告 | 医生诊断 | 病因诊断 |
| 预测性 | 将会怎样？ | 预测值+置信区间 | 风险预警 | 病情预判 |
| **处方性** | **应该怎么做？** | **行动方案+预期ROI** | **医生开处方** | **治疗方案** |

### 1.3 处方性分析的三大方法

| 方法 | 核心逻辑 | 适用场景 | 成本 | 生活类比 |
|------|----------|----------|------|----------|
| **情景分析** | 模拟不同条件下的结果 | 战略决策、预算规划 | 低 | 下棋时想"如果走这步会怎样" |
| **A/B 测试** | 真实实验验证假设 | 产品迭代、营销优化 | 中 | 试穿两件衣服看哪件更好看 |
| **优化分析** | 数学求解最优方案 | 资源分配、定价策略 | 高 | 导航软件计算最快路线 |

## 二、处方性分析四步法

### 2.1 四步法总览

| 步骤 | 核心任务 | 关键问题 | 输出成果 |
|:----:|:--------:|:--------:|:--------:|
| **Step 1** | 定义决策框架 | 目标是什么？限制是什么？选择有哪些？ | 决策框架文档 |
| **Step 2** | 量化每个方案 | 收益多少？成本多少？风险多大？ | 方案评估表 |
| **Step 3** | 敏感性分析 | 如果假设错了会怎样？ | 风险预案 |
| **Step 4** | 决策与追踪 | 推荐哪个方案？如何追踪效果？ | 决策输出文档 |

### 2.2 Step 1：定义决策框架

**用生活例子理解**：

就像规划旅行——先确定目的地（目标），再看预算和时间（约束），最后列出可选路线（方案）。

```python
# 决策框架定义示例
决策框架 = {
    "目标函数": "最大化 Q2 GMV",
    "约束条件": ["预算 500 万", "各渠道最低投入 30 万"],
    "可选方案": ["平均分配", "ROI优先", "GMV最大化", "留存优先"]
}

print("决策框架：")
print(f"目标：{决策框架['目标函数']}")
print("约束：")
for 约束 in 决策框架["约束条件"]:
    print(f"  • {约束}")
print("方案：")
for 方案 in 决策框架["可选方案"]:
    print(f"  • {方案}")
```

### 2.3 Step 2：量化每个方案

**用生活例子理解**：

就像买车——不只看价格，还要看油耗、保养成本、保值率、安全性等。

```python
# 方案量化评估示例
方案评估 = {
    "平均分配": {"GMV": 2176, "ROI": 3.5, "留存用户": 5.93, "风险": "低"},
    "ROI优先": {"GMV": 2067, "ROI": 3.1, "留存用户": 6.10, "风险": "中"},
    "GMV最大化": {"GMV": 2177, "ROI": 3.4, "留存用户": 5.89, "风险": "中"},
    "留存优先": {"GMV": 1890, "ROI": 2.8, "留存用户": 6.42, "风险": "低"}
}

print("方案对比：")
for 方案, 评估 in 方案评估.items():
    print(f"{方案}：GMV {评估['GMV']}万，ROI {评估['ROI']}x，留存 {评估['留存用户']}万，风险 {评估['风险']}")
```

### 2.4 Step 3：敏感性分析

**用生活例子理解**：

就像出门前看天气预报——如果下雨怎么办？带伞。如果刮风怎么办？穿外套。

```python
# 敏感性分析示例
关键假设 = "社交裂变 ROI = 4.2x"
假设变化 = "如果实际 ROI 只有 3.0x"

原预期GMV = 2177
变化后GMV = 1934  # 下降 11%

print("敏感性分析：")
print(f"关键假设：{关键假设}")
print(f"假设变化：{假设变化}")
print(f"影响：GMV 从 {原预期GMV}万降至 {变化后GMV}万（下降 11%）")
print("预案：如果 ROI < 3.5x，立即将预算转向搜索广告")
```

### 2.5 Step 4：决策与追踪

**用生活例子理解**：

就像医生开处方后还要随访——药吃了效果如何？有没有副作用？需要调整吗？

```python
# 决策输出模板
决策输出 = {
    "推荐方案": "GMV 最大化方案",
    "预期结果": "GMV 2177万，ROI 3.4x",
    "关键假设": ["社交裂变 ROI 4.2x", "搜索广告 ROI 3.5x"],
    "风险预案": "如果裂变 ROI < 3.5x，转向搜索广告",
    "追踪指标": ["每周检查各渠道 ROI", "每月复盘 GMV"],
    "决策检查点": "5月15日复盘，决定是否调整"
}

print("决策输出：")
for 项目, 内容 in 决策输出.items():
    if isinstance(内容, list):
        print(f"{项目}：")
        for 条目 in 内容:
            print(f"  • {条目}")
    else:
        print(f"{项目}：{内容}")
```

## 四、实战案例：A/B 测试 —— 商品详情页改版

### 4.1 业务背景

> 产品团队提出将商品详情页从"上图下文"改为"左图右文"布局，需要用 A/B 测试验证效果。

### 4.2 实验设计

**用生活例子理解**：

就像试穿两件衣服看哪件更好看——不能只看一眼就决定，要穿一段时间、问朋友意见、看实际效果。

```python
# A/B 测试设计
实验参数 = {
    "假设": "新布局能提升加购转化率",
    "显著性水平": 0.05,
    "基线转化率": 0.12,  # 当前加购率 12%
    "最小可检测效应": 0.015,  # 提升 1.5%
    "每组样本量": 6900,
    "总样本量": 13800
}

print("A/B 测试设计：")
for 参数, 值 in 实验参数.items():
    print(f"• {参数}：{值}")
```

### 4.3 实验结果（14 天）

| 指标 | 对照组（旧版） | 实验组（新版） | 差异 | p值 | 显著性 |
|------|-------------|-------------|------|-----|:------:|
| 样本量 | 7,200 | 7,150 | — | — | — |
| 加购率 | 12.1% | 13.8% | **+1.7%** | 0.008 | ✅ |
| 下单率 | 5.2% | 5.5% | +0.3% | 0.28 | ❌ |
| 页面停留时长 | 45s | 52s | +7s | 0.001 | ✅ |
| 跳出率 | 38% | 33% | -5% | 0.002 | ✅ |

### 4.4 结果分析

```python
# A/B 测试结果分析
结果分析 = {
    "加购率": {"变化": "+1.7%", "p值": 0.008, "结论": "显著提升 ✅"},
    "下单率": {"变化": "+0.3%", "p值": 0.28, "结论": "未显著 ❌"},
    "停留时长": {"变化": "+15.6%", "p值": 0.001, "结论": "显著增加 ✅"},
    "跳出率": {"变化": "-13.2%", "p值": 0.002, "结论": "显著降低 ✅"}
}

print("统计检验结果：")
for 指标, 结果 in 结果分析.items():
    print(f"{指标}：{结果['变化']}，p={结果['p值']}，{结果['结论']}")

# ROI 估算
日均加购增量 = 120  # 人
加购到下单转化率 = 0.43
日均下单增量 = int(日均加购增量 * 加购到下单转化率)  # 52 单
客单价 = 140
日均GMV增量 = 日均下单增量 * 客单价  # 7280 元
月GMV增量 = 日均GMV增量 * 30  # 21.8 万

print(f"\nROI 估算：")
print(f"日均多 {日均加购增量} 人加购")
print(f"日均多 {日均下单增量} 单")
print(f"月增量 GMV ≈ {月GMV增量:.1f} 万")
print("建议：上线新版本，持续监控下单转化率")
```

```python
# 阶梯定价方案
```

## 六、常见误区与纠正

| 误区 | 表现 | 后果 | 纠正方法 | 生活类比 |
|------|------|------|----------|----------|
| 唯一最优解 | 认为存在一个完美方案 | 错误决策 | 所有方案都有 trade-off，选最适合目标的 | 没有完美的车，只有最适合你的车 |
| 忽略机会成本 | 只比较方案本身 | 误判收益 | 还要考虑"不做会怎样" | 买车不只看车价，还要看省下的钱能做什么 |
| 忽略可逆性 | 所有决策都当不可逆 | 过度谨慎 | 可逆决策快速试，不可逆决策慎重 | 点错菜可以重点，选错专业很难换 |
| 过度分析 | 永远在分析，从不决策 | 错失机会 | 设定决策截止时间 | 看了100家餐厅还是不知道吃什么 |
| 忽略执行成本 | 方案好但执行不了 | 无法落地 | 评估方案时纳入实施难度 | 健身卡办了不代表会去健身 |
| A/B 测试偷看 | 中途看结果就下结论 | 错误结论 | 必须跑完预定样本量 | 菜还没熟就尝，会误判 |

**误区纠正实例**：

```python
# 误区：忽略可逆性
错误做法 = "所有决策都用处方性分析，耗时耗力"

# 纠正：按重要性和可逆性分类
决策类型 = {
    "Type1_高重要不可逆": "深度分析+慎重决策（公司战略转型）",
    "Type2_高重要可逆": "快速实验+迭代优化（产品改版）",
    "Type3_低重要不可逆": "标准流程+快速决策（供应商选择）",
    "Type4_低重要可逆": "快速决策+随时调整（UI颜色）"
}

print("决策分类：")
for 类型, 方式 in 决策类型.items():
    print(f"{类型}：{方式}")
```

## 七、即时练习

> **题目**：某内容平台需要选择用户增长策略，有以下数据：

| 策略 | 月投入(万) | 预计新增(万) | 次日留存 | 7日留存 | 获客成本 |
|------|-----------|-------------|---------|---------|---------|
| A.买量投放 | 50 | 5 | 30% | 10% | 10元 |
| B.裂变活动 | 30 | 8 | 45% | 22% | 3.75元 |
| C.KOL种草 | 40 | 3 | 52% | 28% | 13.3元 |
| D.SEO优化 | 15 | 1.5 | 55% | 30% | 10元 |

预算 100 万，请设计最优组合方案。

**参考分析**：

```python
# 策略评估
策略评估 = {
    "A买量": {"量级": 4, "质量": 1, "效率": 3, "可扩展": 5},
    "B裂变": {"量级": 5, "质量": 3, "效率": 5, "可扩展": 4},
    "CKOL": {"量级": 2, "质量": 4, "效率": 2, "可扩展": 3},
    "DSEO": {"量级": 1, "质量": 5, "效率": 3, "可扩展": 2}
}

print("策略评估（星级）：")
for 策略, 评估 in 策略评估.items():
    print(f"{策略}：量级{评估['量级']}★ 质量{评估['质量']}★ 效率{评估['效率']}★ 扩展{评估['可扩展']}★")
```

## 总结

| 内容 | 要点 |
|-----|------|
| 处方性分析 | 回答"应该怎么做"，给出行动方案+预期ROI |
| 三大方法 | 情景分析、A/B测试、优化分析 |
| 四步法 | 定义框架 → 量化方案 → 敏感性分析 → 决策追踪 |
| 情景分析 | 模拟不同决策的结果，选择最优方案 |
| A/B测试 | 真实实验验证假设，统计显著性检验 |
| 优化分析 | 数学求解最优方案，如定价策略 |
| 常见误区 | 唯一最优解、忽略机会成本、忽略可逆性、过度分析 |
