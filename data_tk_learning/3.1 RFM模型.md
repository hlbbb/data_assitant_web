# 3.1 RFM 模型 —— 用户价值分层经典方法

> RFM 模型是用户价值分层的经典方法——通过最近消费时间、消费频次、消费金额三个维度，快速回答"谁是你的好用户"。学完这章，你能精准识别高价值用户，合理分配运营资源。

**学完这章你能干啥？**
- 能用 RFM 三维度对用户进行价值分层
- 知道 R 是反向指标（越小越好），避免打分错误
- 能识别八类用户群体并制定差异化策略
- 避免分层后无策略、周期一刀切等常见误区

---

## 一、什么是 RFM 模型？

### 1.1 用生活例子理解

**用生活例子理解**：

就像银行给你打信用分——看你最近有没有按时还款（R），历史上还款次数多不多（F），欠了多少钱（M）。三个维度综合起来，银行就知道你是"优质客户"还是"风险客户"。

**代码示例**：

```python
# RFM 三维度定义
RFM定义 = {
    "R": "最近一次消费距今天数（越小越好）",
    "F": "统计周期内购买次数（越大越好）",
    "M": "统计周期内消费总额（越大越好）"
}

# 用户价值判断逻辑
用户价值 = {
    "高价值": "R小（最近消费）+ F大（高频）+ M大（高金额）",
    "中价值": "部分维度高，部分维度低",
    "低价值": "R大（久未消费）+ F小（低频）+ M小（低金额）"
}

print("RFM 核心逻辑：最近买过、经常买、花得多的人，就是最有价值的用户")
```

**专业术语**：

RFM 是一种基于用户交易行为进行**价值分层**的经典模型，通过三个维度将用户划分为不同的群体，从而实现精准运营。

### 1.2 RFM 三维度详解

| 维度 | 英文 | 含义 | 衡量方式 | 为什么重要 |
|------|------|------|----------|-----------|
| **R** (Recency) | 最近一次消费 | 用户最近一次购买距今天数 | **越小越好** | 反映用户活跃状态 |
| **F** (Frequency) | 消费频次 | 统计周期内购买次数 | 越大越好 | 反映用户忠诚度 |
| **M** (Monetary) | 消费金额 | 统计周期内消费总额 | 越大越好 | 反映用户价值贡献 |

### 1.3 为什么 R 是反向指标？

**用生活例子理解**：

R 就像"你多久没给妈妈打电话了"：

```python
# R 值的生活类比
R值类比 = {
    "R=3天": "刚打过，感情热乎 → 活跃用户 → 高分",
    "R=30天": "还行，感情正常 → 一般用户 → 中分",
    "R=90天": "很久了，有点疏 → 流失风险 → 低分",
    "R=365天": "一年没联系，感情淡了 → 已流失 → 最低分"
}

print("关键理解：R 数值越大 = 感情越淡 = 得分越低")
print("          R 数值越小 = 感情越热 = 得分越高")
print("这就是'反向指标'的本质！")
```

| R 值 | 含义 | 打分 | 原因 |
|------|------|:----:|------|
| 3 天 | 刚消费 | 5分 | R越小 = 越活跃 = 分越高 |
| 30 天 | 本月消费 | 4分 | |
| 90 天 | 上季消费 | 3分 | |
| 180 天 | 半年前 | 2分 | |
| 365 天 | 一年前 | 1分 | R越大 = 越流失 = 分越低 |

> **核心口诀**：R 反向（小值高分），F/M 正向（大值高分）

### 1.4 为什么选择 RFM？

| 场景 | 无 RFM | 有 RFM |
|------|--------|--------|
| 用户运营 | 一刀切群发，效率低 | 分层精准触达，ROI 高 |
| 营销预算 | 平均分配给所有用户 | 聚焦高价值用户 |
| 流失预警 | 流失了才知道 | 提前识别并挽留 |
| 活动设计 | 一套方案所有人 | 不同层级不同方案 |

## 二、RFM 分析五步法

### 2.1 五步法总览

| 步骤 | 核心任务 | 关键问题 | 输出成果 |
|:----:|:--------:|:--------:|:--------:|
| **Step 1** | 确定分析周期 | 分析多长时间的数据？ | 分析周期设定 |
| **Step 2** | 计算 RFM 原始值 | 每个用户的 R/F/M 是多少？ | RFM 原始值表 |
| **Step 3** | RFM 评分 | 如何给每个维度打分？ | RFM 评分表 |
| **Step 4** | 设定阈值分层 | 如何划分用户类型？ | 八类用户分层 |
| **Step 5** | 制定运营策略 | 每类用户该如何运营？ | 运营策略方案 |

### 2.2 Step 1：确定分析周期

**用生活例子理解**：

就像体检——如果你想知道最近身体状况，就看最近一个月的数据；想知道长期健康状况，就看过去一年的数据。

| 业务类型 | 推荐分析周期 | 原因 | 生活类比 |
|----------|-------------|------|----------|
| 快消电商 | 3-6 个月 | 购买频次高，周期短 | 日用品用得快，要看近期 |
| 服装电商 | 6-12 个月 | 季节性购买 | 衣服换季买，要看全年 |
| 3C 数码 | 12-24 个月 | 复购周期长 | 手机电脑几年才换一次 |
| B2B SaaS | 12 个月 | 年度续费周期 | 企业年度订阅 |

### 2.4 Step 3：RFM 评分（五分位法）

**用生活例子理解**：

就像考试成绩分档——90-100分是A档，80-89分是B档，70-79分是C档。每个档位对应一个等级。

```python
# RFM 评分规则（五分位法）
评分规则 = {
    "R评分": {
        "0-7天": 5,    # 本周消费，最活跃
        "8-30天": 4,   # 本月消费
        "31-90天": 3,  # 上季消费
        "91-180天": 2, # 半年内
        ">180天": 1    # 超过半年，最不活跃
    },
    "F评分": {
        "≥10次": 5,    # 超高频
        "6-9次": 4,    # 高频
        "3-5次": 3,    # 中频
        "2次": 2,      # 低频
        "1次": 1       # 极低频
    },
    "M评分": {
        "≥5000": 5,    # 高消费
        "2000-4999": 4, # 中高
        "800-1999": 3,  # 中等
        "300-799": 2,   # 低消费
        "<300": 1       # 极低消费
    }
}

# 计算评分
def get_R_score(R):
    if R <= 7: return 5
    elif R <= 30: return 4
    elif R <= 90: return 3
    elif R <= 180: return 2
    else: return 1

def get_F_score(F):
    if F >= 10: return 5
    elif F >= 6: return 4
    elif F >= 3: return 3
    elif F == 2: return 2
    else: return 1

def get_M_score(M):
    if M >= 5000: return 5
    elif M >= 2000: return 4
    elif M >= 800: return 3
    elif M >= 300: return 2
    else: return 1

# 对用户打分
for 用户 in 用户数据:
    用户["R分"] = get_R_score(用户["R"])
    用户["F分"] = get_F_score(用户["F"])
    用户["M分"] = get_M_score(用户["M"])
    用户["总分"] = 用户["R分"] + 用户["F分"] + 用户["M分"]

print("RFM 评分结果：")
for 用户 in 用户数据:
    print(f"{用户['用户']}：R分={用户['R分']}，F分={用户['F分']}，M分={用户['M分']}，总分={用户['总分']}")
```

**评分结果表**：

| 用户 | R天数 | R分 | F次数 | F分 | M金额 | M分 | RFM总分 |
|------|-------|:----:|-------|:----:|-------|:----:|:-------:|
| 用户A | 5天 | **5** | 12次 | **5** | 4,800元 | **4** | **14** |
| 用户B | 61天 | **3** | 3次 | **3** | 1,200元 | **3** | **9** |
| 用户C | 25天 | **4** | 8次 | **4** | 6,500元 | **5** | **13** |
| 用户D | 165天 | **2** | 1次 | **1** | 320元 | **2** | **4** |
| 用户E | 3天 | **5** | 6次 | **4** | 2,100元 | **4** | **13** |

### 2.5 Step 4：八类用户分层

**用生活例子理解**：

就像把学生分成八个班——成绩好的去重点班，成绩一般的去普通班，成绩差的去补习班。每个班的教学方式不同。

以各维度均值（R=3, F=3, M=3）为阈值，划分八种用户类型：

```python
# 八类用户分层逻辑
def classify_user(R分, F分, M分, 均值=3):
    R高 = R分 >= 均值  # 最近消费（活跃）
    F高 = F分 >= 均值  # 高频消费（忠诚）
    M高 = M分 >= 均值  # 高金额消费（高价值）
    
    if R高 and F高 and M高:
        return "重要价值用户"
    elif R高 and not F高 and M高:
        return "重要发展用户"
    elif not R高 and F高 and M高:
        return "重要保持用户"
    elif not R高 and not F高 and M高:
        return "重要挽留用户"
    elif R高 and F高 and not M高:
        return "一般价值用户"
    elif R高 and not F高 and not M高:
        return "一般发展用户"
    elif not R高 and F高 and not M高:
        return "一般保持用户"
    else:
        return "一般挽留用户"

# 分类用户
for 用户 in 用户数据:
    用户["类型"] = classify_user(用户["R分"], 用户["F分"], 用户["M分"])

print("用户分层结果：")
for 用户 in 用户数据:
    print(f"{用户['用户']}：{用户['类型']}")
```

**八类用户特征速查表**：

| 用户类型 | RFM特征 | 典型画像 | 风险点 | 优先级 |
|---------|---------|---------|--------|:------:|
| **重要价值用户** | R↑F↑M↑ | 刚买过、常买、花得多 | 被竞品挖走 | ⭐⭐⭐⭐⭐ |
| **重要发展用户** | R↑F↓M↑ | 刚买过、买得少、花得多 | 转化为一次性客户 | ⭐⭐⭐⭐ |
| **重要保持用户** | R↓F↑M↑ | 久未买、常买、花得多 | 正在流失 | ⭐⭐⭐⭐⭐ |
| **重要挽留用户** | R↓F↓M↑ | 久未买、买得少、花得多 | 高价值流失 | ⭐⭐⭐⭐ |
| **一般价值用户** | R↑F↑M↓ | 刚买过、常买、花得少 | 贡献有限 | ⭐⭐⭐ |
| **一般发展用户** | R↑F↓M↓ | 刚买过、买得少、花得少 | 转化失败 | ⭐⭐⭐ |
| **一般保持用户** | R↓F↑M↓ | 久未买、常买、花得少 | 低价值流失 | ⭐⭐ |
| **一般挽留用户** | R↓F↓M↓ | 久未买、买得少、花得少 | 无价值 | ⭐ |

## 四、RFM 进阶用法

### 4.1 加权 RFM 模型

**用生活例子理解**：

就像考试——语文、数学、英语的重要性不同，所以要按权重算总分。

```python
# 加权 RFM 模型
权重设置 = {
    "电商（重复购）": {"R": 0.3, "F": 0.4, "M": 0.3},
    "奢侈品（重金额）": {"R": 0.2, "F": 0.2, "M": 0.6},
    "SaaS（重活跃）": {"R": 0.5, "F": 0.3, "M": 0.2},
    "订阅制（重续费）": {"R": 0.4, "F": 0.4, "M": 0.2}
}

# 计算加权得分
def calculate_weighted_score(R分, F分, M分, 权重):
    return 权重["R"] * R分 + 权重["F"] * F分 + 权重["M"] * M分

电商权重 = 权重设置["电商（重复购）"]
加权得分 = calculate_weighted_score(5, 5, 4, 电商权重)

print(f"电商场景加权得分：{加权得分}")
print(f"权重：R={电商权重['R']}, F={电商权重['F']}, M={电商权重['M']}")
```

## 五、常见误区与纠正

| 误区 | 表现 | 后果 | 纠正方法 |
|------|------|------|----------|
| **忽略 R 方向** | R 值直接正向打分 | 高分给了流失用户 | R 是反向指标，需反转评分 |
| **周期一刀切** | 所有业务用同一周期 | 数据失真 | 按行业特征选择周期 |
| **只看静态分层** | 不做动态追踪 | 无法预警流失 | 每月追踪层级迁移 |
| **阈值定死不变** | 用固定阈值分所有时期 | 分层失效 | 随业务增长动态调整 |
| **分层后无策略** | 分了八类但运营动作一样 | 分层无意义 | 每类必须有差异化策略 |
| **过度细分** | 拆出 20+ 个层级 | 无法落地 | 八类足够，过多则无法执行 |

**最常见误区详解**：

```python
# 误区：忽略 R 的反向逻辑
错误做法 = {
    "R=180天": "直接打5分 → 误判为'高价值用户'",
    "R=5天": "直接打1分 → 误判为'低价值用户'"
}

正确做法 = {
    "R=180天": "反转打1分 → 正确识别为'流失用户'",
    "R=5天": "反转打5分 → 正确识别为'活跃用户'"
}

print("为什么会犯错？")
print("因为 F 和 M 都是'越大越好'，容易形成思维惯性")
print("误以为 R 也是'越大越好'，这是最典型的 RFM 陷阱！")
```

## 总结

| 内容 | 要点 |
|-----|------|
| RFM 模型 | 通过 R（最近消费）、F（消费频次）、M（消费金额）三维度分层用户 |
| 反向指标 | R 是反向指标（越小越好），千万别正向打分 |
| 五步法 | 确定周期 → 计算原始值 → 评分 → 分层 → 制定策略 |
| 八类用户 | 重要价值/发展/保持/挽留 + 一般价值/发展/保持/挽留 |
| 预算分配 | 二八法则：20%高价值用户分配80%运营资源 |
| 常见误区 | R反向、周期一刀切、只看静态、无策略、过度细分 |
