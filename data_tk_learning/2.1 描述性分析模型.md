# 2.1 描述性分析模型 —— "发生了什么"

> 描述性分析是数据分析的基础——连发生了什么都不知道，就无法往下深挖。学完这章，你能把任何数据变成清晰的业务故事。

**学完这章你能干啥？**
- 能用趋势、分布、构成三大视角分析数据
- 知道什么时候用均值、什么时候用中位数
- 能发现数据中的异常和关键变化
- 写出清晰的描述性分析报告

---

## 一、什么是描述性分析？

### 1.1 用生活例子理解

**用生活例子理解**：

就像体检报告，医生不会直接告诉你"为什么生病"或"怎么治"，而是先列出各项指标——血压多少、血糖多少、心率多少。

描述性分析就是给业务做一次"全面体检"，把各项数据指标摆出来，让大家看清现状。

**代码示例**：

```python
# 描述性分析：回答"发生了什么"
本月营收 = 3200000
上月营收 = 3600000
环比变化 = (本月营收 - 上月营收) / 上月营收

print(f"本月营收: {本月营收}元")
print(f"上月营收: {上月营收}元")
print(f"环比变化: {环比变化:.1%}")  # -11.1%
# 结论：营收环比下降 11.1%，这是"发生了什么"
```

**专业术语**：

描述性分析（Descriptive Analytics）是对已发生的事情进行**量化总结和呈现**，回答"发生了什么"。它是所有分析的基础。

### 1.2 数据分析的四个层次

| 分析层次 | 核心问题 | 生活类比 | 复杂度 |
|----------|----------|----------|:------:|
| **描述性** | 发生了什么？ | 体检报告告诉你"血压 150/95" | ⭐ |
| **诊断性** | 为什么发生？ | 医生分析"是因为肥胖、饮食不规律" | ⭐⭐ |
| **预测性** | 将会发生什么？ | 医生预测"不控制会得心脏病" | ⭐⭐⭐ |
| **处方性** | 应该怎么做？ | 医生建议"减肥、吃药、定期复查" | ⭐⭐⭐⭐ |

### 1.3 描述性分析的三大武器

| 武器 | 核心问题 | 典型方法 | 输出形式 | 生活类比 |
|------|----------|----------|----------|----------|
| **趋势分析** | 随时间怎么变化？ | 时间序列、移动平均 | 折线图 | 记账本：看每月支出是涨是跌 |
| **分布分析** | 数据散成什么样？ | 频数分布、百分位 | 直方图、箱线图 | 班级成绩：看分数是集中还是分散 |
| **构成分析** | 各部分占比如何？ | 占比分析、帕累托 | 饼图、堆积图 | 家庭开支：看钱都花在哪些地方 |

## 二、核心指标速查

### 2.1 集中趋势指标（描述数据的"中心位置"）

**用生活例子理解**：

就像班级成绩，你想知道"大家考得怎么样"，需要一个代表值。但不同场景用不同的代表值。

| 指标 | 专业定义 | 计算公式 | 适用场景 | 生活例子 |
|------|----------|----------|----------|----------|
| **均值（Mean）** | 所有数值的算术平均 | Σx / n | 数据分布均匀、无极端值 | 班级平均分：但被学霸拉高 |
| **中位数（Median）** | 排序后中间位置的值 | 第 (n+1)/2 个值 | 数据有极端值、偏态分布 | 班级成绩中位数：更真实反映"中等水平" |
| **众数（Mode）** | 出现次数最多的值 | 频数最高的值 | 分类数据、离散数据 | 最常见的鞋码：商家进货参考 |

**选择指南**：

```python
# 判断用均值还是中位数
收入数据 = [3000, 3500, 4000, 4500, 5000, 100000]  # 有极端值

均值 = sum(收入数据) / len(收入数据)  # 约 20000，被大值拉高
中位数 = 4500  # 更真实反映"中等水平"

print(f"均值: {均值}元")  # 被极端值拉高，不具代表性
print(f"中位数: {中位数}元")  # 更真实

if 均值 > 中位数 * 1.5:
    print("建议：使用中位数，数据右偏严重")
```

| 数据特征 | 推荐指标 | 原因 |
|----------|----------|------|
| 正态分布（对称） | 均值 | 三者接近，均值信息量最大 |
| 右偏分布（长尾在右） | 中位数 | 均值被大值拉高，不具代表性 |
| 左偏分布（长尾在左） | 中位数 | 均值被小值拉低，不具代表性 |
| 分类数据 | 众数 | 无法计算均值/中位数 |

### 2.2 离散程度指标（描述数据的"分散程度"）

**用生活例子理解**：

两个班级平均分都是 80 分，但 A 班分数在 75-85 之间，B 班分数在 50-100 之间。离散程度告诉你"数据有多散"。

| 指标 | 专业定义 | 取值范围 | 适用场景 | 生活例子 |
|------|----------|----------|----------|----------|
| **极差（Range）** | 最大值 - 最小值 | [0, +∞) | 快速了解数据跨度 | 最高分-最低分：差距有多大 |
| **标准差（SD）** | 方差的平方根 | [0, +∞) | 最常用离散指标 | 平均偏离均值多少分 |
| **变异系数（CV）** | 标准差 / 均值 | [0, +∞) | 比较不同量纲数据 | 身高波动 vs 体重波动，谁更稳定 |
| **四分位距（IQR）** | 上四分位 - 下四分位 | [0, +∞) | 有极端值时使用 | 中间 50% 数据的跨度 |

```python
# 离散程度计算示例
A班成绩 = [75, 78, 80, 82, 85]
B班成绩 = [50, 60, 80, 95, 100]

A班极差 = max(A班成绩) - min(A班成绩)  # 10
B班极差 = max(B班成绩) - min(B班成绩)  # 50

print(f"A班极差: {A班极差}")  # 分数集中
print(f"B班极差: {B班极差}")  # 分数分散
print("结论：B班成绩波动大，需要分层教学")
```

### 2.3 分布形态指标

| 指标 | 取值含义 | 分布形态 | 生活例子 |
|------|----------|----------|----------|
| **偏度** | = 0：对称<br>> 0：右偏<br>< 0：左偏 | 正态分布偏度=0 | 收入分布：右偏（少数人收入极高） |
| **峰度** | = 0：正态峰<br>> 0：尖峰<br>< 0：平峰 | 正态分布峰度=0 | 考试成绩：尖峰=分数集中，平峰=分数分散 |

### 2.4 相关性指标

**用生活例子理解**：

就像看"身高"和"体重"的关系——身高增加，体重是否也增加？

| 指标 | 取值范围 | 含义解读 |
|------|----------|----------|
| **皮尔逊相关系数（r）** | [-1, 1] | r=1：完全正相关<br>r=-1：完全负相关<br>r=0：无线性相关 |

**相关强度判断**：

| \|r\| 值 | 相关强度 | 实际意义 |
|----------|----------|----------|
| 0.0-0.2 | 极弱相关 | 几乎无关系 |
| 0.2-0.4 | 弱相关 | 关系不明显 |
| 0.4-0.6 | 中等相关 | 有一定关系 |
| 0.6-0.8 | 强相关 | 关系明显 |
| 0.8-1.0 | 极强相关 | 关系非常明显 |

## 三、描述性分析五步法

### 3.1 五步法总览

| 步骤 | 核心任务 | 关键问题 | 输出成果 |
|:----:|:--------:|:--------:|:--------:|
| **Step 1** | 明确分析目标 | 业务问题是什么？需要回答"发生了什么"？ | 分析目标清单 |
| **Step 2** | 选择核心指标 | 与目标对齐的指标有哪些？ | 核心指标清单 |
| **Step 3** | 选择分析视角 | 用趋势、分布还是构成视角？ | 分析视角选择 |
| **Step 4** | 计算与可视化 | 数据统计结果是什么？用什么图表？ | 统计结果 + 图表 |
| **Step 5** | 数据叙事 | 如何讲清楚"发生了什么"？ | 分析报告 |

### 3.2 Step 1：明确分析目标

**用生活例子理解**：

就像体检前要明确检查什么——是想查心脏问题？还是想查肝脏问题？目标不同，检查项目不同。

**问自己**：
- 业务问题是什么？
- 需要回答"发生了什么"？
- 关键利益相关者是谁？

### 3.3 Step 2：选择核心指标

**用生活例子理解**：

就像体检选择检查项目——查心脏问题就选心电图、血压；查肝脏问题就选肝功能、B超。

**指标选择原则**：

| 原则 | 说明 | 反例 |
|------|------|------|
| 与目标对齐 | 指标必须服务于业务目标 | 社交APP关注"注册量"而非"活跃度" |
| 可归因 | 指标能拆解到具体行动 | "品牌影响力"无法归因 |
| 前后一致 | 口径不随意变更 | 本月突然改了"活跃"的定义 |

### 3.4 Step 3：选择分析视角

**用生活例子理解**：

就像看一座山——可以从东面看（看到山顶），可以从南面看（看到山腰），可以从西面看（看到山脚）。不同视角看到不同的风景。

**同一组数据，不同视角有不同结论**：

| 视角 | 问题 | 生活类比 |
|------|------|----------|
| 趋势视角 | 随时间怎么变？ | 记账本看每月支出变化 |
| 分布视角 | 数据散成什么样？ | 班级成绩看分数分布 |
| 构成视角 | 各部分怎么组成？ | 家庭开支看钱花在哪 |
| 对比视角 | 跟谁比差多少？ | 考试排名看自己位置 |

### 3.5 Step 4：计算与可视化

**用生活例子理解**：

就像选择合适的容器装东西——液体用杯子，固体用盘子，粉末用罐子。不同类型的数据要用不同的图表。

| 数据类型 | 分析目的 | 推荐图表 | 注意事项 |
|----------|----------|----------|----------|
| 时间序列 | 看趋势变化 | 折线图 | 时间间隔要一致 |
| 分类数据 | 看占比构成 | 饼图 | 类别 < 7 个 |
| 分类数据 | 看排名对比 | 条形图 | 按数值排序 |
| 数值分布 | 看分布形态 | 直方图 | 分组数量要合理 |
| 数值分布 | 看分布特征 | 箱线图 | 标注异常值 |
| 相关关系 | 看两变量关系 | 散点图 | 可添加趋势线 |

**图表设计原则**：

| 原则 | 说明 | 反例 |
|------|------|------|
| 一图一意 | 每张图表只传达一个核心信息 | 一张图塞 10 个指标 |
| 突出重点 | 用颜色、标注强调关键数据 | 所有数据用相同颜色 |
| 简洁清晰 | 去除不必要的装饰元素 | 3D 效果、渐变背景 |
| 准确真实 | 坐标轴从 0 开始，避免误导 | Y 轴截断夸大变化 |

### 3.6 Step 5：数据叙事

**用生活例子理解**：

就像医生看完体检报告后告诉你——"你的血压偏高，最近要注意饮食，少吃盐"。数据叙事就是把数据变成清晰的业务故事。

**数据叙事的 STAR 结构**：

```python
# STAR 结构示例
报告 = {
    "S背景": "Q1 MRR 连续增长，累计增长 10.7%",
    "T转折": "4月 MRR 首次下降 1.6%",
    "A分析": "大客户流失加速 + 新增放缓是主因",
    "R建议": "启动大客户挽留 + 加大获客投入"
}

print("描述性分析报告：")
for 部分, 内容 in 报告.items():
    print(f"{部分}：{内容}")
```

## 四、实战案例：SaaS 产品月度经营分析

### 4.1 业务背景

> 某 B2B SaaS 产品，2025 年 Q1 经营数据如下，需要做一份完整的描述性分析报告。

### 4.2 原始数据

| 月份 | MRR(万) | 新增客户 | 流失客户 | NPS | 客服工单 | 平均响应(h) |
|------|---------|---------|---------|-----|---------|------------|
| 1月 | 280 | 45 | 12 | 62 | 320 | 4.2 |
| 2月 | 295 | 52 | 15 | 58 | 380 | 5.1 |
| 3月 | 310 | 48 | 22 | 55 | 450 | 6.8 |
| 4月 | 305 | 38 | 28 | 48 | 520 | 8.5 |

### 4.3 趋势分析：看时间变化

```python
# MRR 趋势分析
MRR数据 = [280, 295, 310, 305]

环比变化 = []
for i in range(1, len(MRR数据)):
    变化 = (MRR数据[i] - MRR数据[i-1]) / MRR数据[i-1]
    环比变化.append(变化)

print("MRR 趋势分析：")
print("1月→2月：环比 +5.4%")
print("2月→3月：环比 +5.1%")
print("3月→4月：环比 -1.6% ← 首次负增长！")

# 新增客户趋势
print("\n新增客户趋势：")
print("1月→2月：环比 +15.6%")
print("2月→3月：环比 -7.7%")
print("3月→4月：环比 -20.8% ← 加速下滑！")
```

**趋势发现表**：

| 指标 | 1月 | 2月 | 3月 | 4月 | 趋势判断 |
|------|-----|-----|-----|-----|----------|
| MRR(万) | 280 | 295(+5.4%) | 310(+5.1%) | 305(-1.6%) | 🔴 首次下降 |
| 新增客户 | 45 | 52(+15.6%) | 48(-7.7%) | 38(-20.8%) | 🔴 加速下滑 |
| 流失客户 | 12 | 15(+25%) | 22(+46.7%) | 28(+27.3%) | 🔴 持续恶化 |
| NPS | 62 | 58(-4) | 55(-3) | 48(-7) | 🔴 持续下降 |

### 4.4 分布分析：看数据分布

```python
# 客户 MRR 分布分析
客户MRR = {
    "≥5万/月": {"客户数": 8, "占比": 0.016, "MRR贡献": 82},
    "1-5万/月": {"客户数": 45, "占比": 0.09, "MRR贡献": 98},
    "5000-1万/月": {"客户数": 120, "占比": 0.24, "MRR贡献": 72},
    "1000-5000/月": {"客户数": 200, "占比": 0.40, "MRR贡献": 42},
    "<1000/月": {"客户数": 127, "占比": 0.254, "MRR贡献": 11}
}

# 计算集中度
头部客户占比 = 0.016 + 0.09  # 10.6%
头部MRR贡献 = (82 + 98) / 305  # 59%

print(f"头部 10.6% 的客户贡献 {头部MRR贡献:.0%} 的 MRR")
print("分布特征：右偏严重，少数大客户贡献大部分收入")
```

**分布特征表**：

| MRR 区间 | 客户数 | 占比 | MRR贡献 | 累计MRR贡献 |
|----------|--------|------|---------|-------------|
| ≥5万/月 | 8 | 1.6% | 82万 | 26.9% |
| 1-5万/月 | 45 | 9.0% | 98万 | 59.0% |
| 5000-1万/月 | 120 | 24.0% | 72万 | 82.6% |
| 1000-5000/月 | 200 | 40.0% | 42万 | 96.4% |
| <1000/月 | 127 | 25.4% | 11万 | 100% |

**关键发现**：
- 头部 10.6% 的客户贡献 59% 的 MRR
- 分布严重右偏，均值 6100元，中位数 3500元

### 4.5 构成分析：看占比结构

```python
# MRR 构成分析
MRR构成 = {
    "存量客户续费": {"金额": 265, "占比": 0.869},
    "新客户贡献": {"金额": 28, "占比": 0.092},
    "升级增量": {"金额": 12, "占比": 0.039},
    "降级减量": {"金额": -15, "占比": -0.049},
    "流失减量": {"金额": -18, "占比": -0.059}
}

净新增MRR = 28 + 12 - 15 - 18  # 7万
print(f"净新增 MRR: {净新增MRR}万（环比：1月+19万 → 4月+7万）")
print("关键风险：流失减量占比最高（-5.9%）")
```

**帕累托分析**：

| 客户排名 | 累计客户% | 累计MRR% | 备注 |
|---------|----------|---------|------|
| 前 50 家 | 10% | 58% | 10% 客户贡献 58% |
| 前 100 家 | 20% | 78% | 20% 客户贡献 78% |
| 其余 400家 | 80% | 22% | 80% 客户仅贡献 22% |

### 4.6 一页纸分析报告

```python
# 一页纸报告
报告 = """
【SaaS 产品 4 月经营分析报告】

一句话结论：4月 MRR 首次环比下降，核心原因是大客户流失加速 + 新增放缓

【核心指标】

• 新增客户 38家 ↓20.8%（加速下滑）
• 流失客户 28家 ↑27.3%（持续恶化）

【关键发现】
• 趋势：前3月月均增长15万，4月首次下跌

【需关注】
1. 立即启动大客户挽留计划（3家大客户流失占流失额52%）
2. 客服响应时间从4.2h恶化到8.5h → 排查 staffing 问题
3. 新增客户连续2月下滑 → 排查销售渠道
"""

print(报告)
```

## 五、常见误区与纠正

| 误区 | 表现 | 后果 | 纠正方法 |
|------|------|------|----------|
| 只看均值不看分布 | "ARPU 6100 元" | 掩盖极端值影响 | 对比均值与中位数判断偏态 |
| 只看总量不看结构 | "MRR 还在涨" | 忽略增长放缓信号 | 拆解构成，看各部分贡献 |
| 指标堆砌无重点 | 20 个指标平铺 | 信息过载，无法聚焦 | 突出 3-5 个核心指标 |
| 缺乏参照系 | "流失 28 家" | 不知道是好是坏 | 对比行业和历史 |
| 描述过度不行动 | 只描述不给出建议 | 分析无价值 | 给出明确的行动建议 |
| 混淆相关与因果 | "A 和 B 相关，所以 A 导致 B" | 错误归因 | 相关≠因果，需进一步验证 |

**误区纠正实例**：

```python
# 误区：只看均值不看分布
错误做法 = "用户平均消费 6100 元"
问题 = "被大客户拉高，不具代表性"

# 纠正
正确做法 = f"均值 6100 元，中位数 3500 元"
判断 = "均值是中位数的 1.74 倍，右偏严重"
建议 = "汇报时应用中位数，或分层展示"

# 误区：缺乏参照系
错误做法 = "流失 28 家客户"
问题 = "不知道是好是坏"

# 纠正
正确做法 = {
    "流失数量": 28,
    "流失率": "5.6%",
    "行业基准": "4%",
    "历史均值": "18家"
}
结论 = "流失率高于行业，数量高于历史均值 → 需关注"
```

## 总结

| 内容 | 要点 |
|-----|------|
| 描述性分析 | 回答"发生了什么"，是所有分析的基础 |
| 三大武器 | 趋势分析、分布分析、构成分析 |
| 核心指标 | 均值/中位数/众数、标准差/IQR、偏度/峰度、相关系数 |
| 五步法 | 明确目标 → 选择指标 → 选择视角 → 计算可视化 → 数据叙事 |
| STAR结构 | 背景 → 转折 → 分析 → 建议 |
| 常见误区 | 只看均值不看分布、缺乏参照系、混淆相关与因果 |
