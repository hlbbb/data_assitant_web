## 一、什么是 LTV 和 CAC？

### 1.1 用生活例子理解

**用生活例子理解**：

想象你开了一家奶茶店：

- 每获得一个新顾客，平均要花 20 元（发传单、打折券、广告）→ 这就是 **CAC**
- 每个顾客平均会来买 10 次奶茶，每次你赚 5 元 → 这就是 **LTV**
- LTV/CAC = 50/20 = 2.5，意味着每花 1 元获客，能赚回 2.5 元

```python
# LTV/CAC 计算
LTV = 50  # 每个顾客贡献的利润
CAC = 20  # 获取一个顾客的成本

健康比值 = LTV / CAC

print(f"LTV = {LTV}元（每个顾客贡献的利润）")
print(f"CAC = {CAC}元（获取一个顾客的成本）")
print(f"LTV/CAC = {健康比值}")

if 健康比值 >= 3:
    print("健康 ✅ 每花1元赚回3元以上")
elif 健康比值 >= 1:
    print("需优化 ⚠️ 勉强回本，利润薄")
else:
    print("亏损 ❌ 每花1元赚不回1元")
```

**专业术语**：

| 指标 | 英文 | 含义 | 本质 | 生活类比 |
|------|------|------|------|----------|
| **LTV** | Life Time Value | 用户在整个生命周期内贡献的利润 | 一个用户值多少钱 | 养一只鸡能下多少蛋 |
| **CAC** | Customer Acquisition Cost | 获取一个新用户的总成本 | 获得一个用户花多少钱 | 买一只小鸡苗要花多少钱 |

### 1.2 LTV/CAC 健康度判断

```python
# LTV/CAC 健康度判断
def judge_health(ltv_cac_ratio):
    if ltv_cac_ratio >= 3:
        return "健康 ✅ （花1元赚回3元以上）"
    elif ltv_cac_ratio >= 1:
        return "需优化 ⚠️ （勉强回本，利润薄）"
    else:
        return "亏损 ❌ （花1元赚不回1元，做慈善）"

# 示例
示例比值 = [0.5, 1.5, 3.0, 5.0]

for 比值 in 示例比值:
    print(f"LTV/CAC = {比值}: {judge_health(比值)}")
```

| LTV/CAC 比值 | 健康度 | 含义 |
|:------------:|:------:|------|
| **< 1.0** | ❌ 亏损 | 每花1元赚不回1元，做一单亏一单 |
| **1.0-3.0** | ⚠️ 需优化 | 勉强盈利，利润薄如纸 |
| **3.0-5.0** | ✅ 健康 | 这是大多数投资人看重的区间 |
| **> 5.0** | 💰 过于保守 | 可能获客投入不足，错失增长机会 |

### 1.3 为什么 LTV/CAC 如此重要？

**用生活例子理解**：

- 获客是支出，留存是收入 → LTV/CAC 把"花钱"和"赚钱"放在同一个天平上
- 不是看"今天赚多少"，而是看"整个生命周期赚多少" → 时间维度的考量
- 先跑通"一个用户"的盈利模型，再规模化复制 → 单位经济模型

| 场景 | 不看 LTV/CAC | 看 LTV/CAC |
|------|-------------|-----------|
| 投放决策 | 哪个渠道便宜投哪个 | 按渠道 LTV/CAC 分配预算 |
| 定价策略 | 凭感觉定价 | 确保价格覆盖 CAC 并留足利润 |
| 融资路演 | "我们有 100 万用户" | "LTV/CAC = 5，单位经济模型健康" |

## 二、核心计算公式

### 2.1 CAC 计算

```python
# CAC 计算示例
广告费 = 1200000  # 120万
营销团队薪资 = 800000  # 80万
活动费用 = 300000  # 30万
工具和数据费用 = 100000  # 10万

总获客成本 = 广告费 + 营销团队薪资 + 活动费用 + 工具和数据费用
新增付费客户 = 52  # 本月新增

CAC = 总获客成本 / 新增付费客户

print(f"总获客成本 = {总获客成本/10000:.0f}万")
print(f"新增付费客户 = {新增付费客户}家")
print(f"CAC = {总获客成本/10000:.0f}万 / {新增付费客户} = {CAC:.0f}元/客户")
```

**CAC 计算公式**：

```
CAC = 总获客成本 ÷ 新增付费客户数

总获客成本包含：
├── 广告费（线上+线下）
├── 营销团队薪资
├── 营销工具和数据费用
├── 活动费用
└── 渠道佣金
```

> **常见错误**：不要漏掉隐性成本（营销团队薪资、工具费用等）

### 2.2 LTV 计算

```python
# LTV 计算（简单估算法）
ARPA = 11905  # 月均每客户收入
毛利率 = 0.72  # 72%
月流失率 = 0.042  # 4.2%

生命周期 = 1 / 月流失率  # 平均留存月数
LTV = ARPA * 毛利率 * 生命周期

print(f"ARPA（月均每客户收入）= {ARPA}元/月")
print(f"毛利率 = {毛利率:.0%}")
print(f"月流失率 = {月流失率:.1%}")
print(f"生命周期 = 1 / {月流失率:.1%} = {生命周期:.1f}个月")
print(f"LTV = {ARPA} × {毛利率:.0%} × {生命周期:.1f} = {LTV:.0f}元")
```

**LTV 三种计算方法**：

| 方法 | 公式 | 适用场景 | 准确度 |
|------|------|----------|:------:|
| **简单估算法** | ARPA × 毛利率 × (1/流失率) | 早期、快速评估 | ⭐⭐ |
| **历史数据法** | Σ(ARPA × 毛利率 × 留存率ⁿ) | 成长期 | ⭐⭐⭐ |
| **Cohort追踪法** | 实际追踪每批用户累计收入 | 成熟期 | ⭐⭐⭐ |

### 2.3 回报周期计算

```python
# 回报周期计算
月均毛利 = ARPA * 毛利率
回报周期 = CAC / 月均毛利

print(f"月均毛利 = {ARPA} × {毛利率:.0%} = {月均毛利:.0f}元")
print(f"回报周期 = {CAC:.0f} / {月均毛利:.0f} = {回报周期:.1f}个月")

if 回报周期 < 6:
    print("回报周期 < 6个月：极佳 ✅")
elif 回报周期 < 12:
    print("回报周期 6-12个月：正常 ⚠️")
else:
    print("回报周期 > 12个月：风险较大 ❌")
```

## 三、实战案例：SaaS 产品 LTV/CAC 分析

### 3.1 业务背景

> 某 B2B SaaS 产品，月 ARR 500 万，需要评估单位经济模型是否健康，为下一轮融资做准备。

### 3.2 计算 CAC

```python
# CAC 分渠道计算
渠道数据 = {
    "内容营销(SEO)": {"成本": 200000, "新客户": 8},
    "线下活动": {"成本": 300000, "新客户": 5},
    "SEM投放": {"成本": 800000, "新客户": 15},
    "销售拓展(BD)": {"成本": 800000, "新客户": 12},
    "合作渠道": {"成本": 500000, "新客户": 12}
}

print("分渠道 CAC 分析：")
for 渠道, 数据 in 渠道数据.items():
    cac = 数据["成本"] / 数据["新客户"]
    print(f"{渠道}：CAC {cac:.0f}元")
```

|------|---------|---------|---------|
| 内容营销(SEO) | 20万 | 8 | **25,000** |
| 线下活动 | 30万 | 5 | 60,000 |
| SEM投放 | 80万 | 15 | 53,333 |
| 销售拓展(BD) | 80万 | 12 | 66,667 |
| 合作渠道 | 50万 | 12 | 41,667 |

### 3.3 计算 LTV

```python
# LTV 分客户等级计算
客户等级数据 = {
    "企业级(≥5万/月)": {"ARPA": 68000, "留存月数": 36, "毛利率": 0.80},
    "专业版(1-5万)": {"ARPA": 22000, "留存月数": 28, "毛利率": 0.75},
```

```python
# 分渠道 LTV/CAC 对比
```

### 3.5 敏感性分析

```python
# 敏感性分析：流失率变化对 LTV/CAC 的影响
基准LTV_CAC = 4.08

场景分析 = {
    "基准": 4.08,
    "流失率降至3%": 5.71,  # 生命周期延长
    "流失率升至6%": 2.85,  # 生命周期缩短
    "CAC上涨30%": 3.14,
    "提价20%": 4.90
}

print("敏感性分析：")
for 场景, 比值 in 场景分析.items():
    变化 = (比值 - 基准LTV_CAC) / 基准LTV_CAC * 100
    print(f"{场景}：LTV/CAC = {比值:.2f}（变化 {变化:+.0f}%）")

print("\n结论：LTV/CAC 对流失率最敏感，控制流失率是最高杠杆")
```

## 四、LTV/CAC 四步法

### 4.1 四步法总览

| 步骤 | 核心任务 | 关键问题 | 输出成果 |
|:----:|:--------:|:--------:|:--------:|
| **Step 1** | 计算 CAC | 获得一个用户花多少钱？ | CAC 数值 |
| **Step 2** | 计算 LTV | 一个用户值多少钱？ | LTV 数值 |
| **Step 3** | 评估健康度 | 商业模式是否健康？ | LTV/CAC 比值 |
| **Step 4** | 找优化杠杆 | 如何提升 LTV/CAC？ | 优化方向 |

### 4.2 Step 1：计算 CAC

**用生活例子理解**：

就像算"养一只鸡的成本"——不能只算饲料钱，还要算鸡舍折旧、人工等隐性成本。

```python
# CAC 计算要点
CAC组成部分 = {
    "广告费": "线上+线下",
    "营销团队薪资": "销售+运营人员",
    "工具和数据费用": "CRM、数据平台等",
    "活动费用": "展会、沙龙等",
    "渠道佣金": "代理商分成"
}

print("CAC 必须包含所有获客成本：")
for 项目, 说明 in CAC组成部分.items():
    print(f"• {项目}：{说明}")
```

### 4.3 Step 2：计算 LTV

```python
# LTV 计算方法选择
def calculate_ltv(ARPA, 毛利率, 月流失率, method="简单估算法"):
    if method == "简单估算法":
        生命周期 = 1 / 月流失率
        return ARPA * 毛利率 * 生命周期
    else:
        return "需要更多历史数据"

# 示例
LTV = calculate_ltv(ARPA=11905, 毛利率=0.72, 月流失率=0.042)
print(f"LTV = {LTV:,.0f}元")
```

### 4.4 Step 3：评估健康度

```python
# 健康度评估
def evaluate_health(LTV, CAC):
    比值 = LTV / CAC
    回报周期 = CAC / (LTV / (1/0.042))  # 简化计算
    
    结果 = {
        "LTV/CAC": 比值,
        "健康度": "健康 ✅" if 比值 >= 3 else "需优化 ⚠️" if 比值 >= 1 else "亏损 ❌"
    }
    return 结果

# 示例
评估结果 = evaluate_health(LTV=203869, CAC=50000)
for 项目, 值 in 评估结果.items():
    print(f"{项目}：{值}")
```

### 4.5 Step 4：找优化杠杆

```python
# 优化杠杆优先级
优化杠杆 = {
    "降低流失率": {"效果": "⭐⭐⭐⭐⭐", "难度": "⭐⭐⭐", "优先级": "★★★★★"},
    "提升客单价": {"效果": "⭐⭐⭐⭐", "难度": "⭐⭐", "优先级": "★★★★"},
    "优化获客渠道": {"效果": "⭐⭐⭐", "难度": "⭐⭐⭐", "优先级": "★★★"},
    "提升转化率": {"效果": "⭐⭐⭐", "难度": "⭐⭐⭐⭐", "优先级": "★★★"},
    "降低CAC": {"效果": "⭐⭐", "难度": "⭐⭐⭐⭐⭐", "优先级": "★★"}
}

print("优化杠杆优先级：")
for 杠杆, 评估 in 优化杠杆.items():

```

> **核心结论**：降低流失率是最高杠杆！

## 五、常见误区与纠正

| 误区 | 表现 | 纠正方法 | 生活类比 |
|------|------|----------|----------|
| 用收入算 LTV | LTV = ARPU × 生命周期 | 应用**毛利**计算 | 算"鸡能下多少蛋"要扣除饲料成本 |
| CAC 只算广告费 | 漏掉人力和工具成本 | 必须包含所有获客相关成本 | 买鸡苗还要算运输、检疫等隐性成本 |
| 忽略时间价值 | 未来 3 年的收入等同于现金 | 折现计算（DCF） | 今天的 100 元比 3 年后的 100 元更值钱 |
| 用均值掩盖分布 | "LTV/CAC = 4"但部分渠道 <1 | 分渠道、分客群分别计算 | 平均身高 1.7 米，但有人 1.5 米有人 1.9 米 |

**最危险的误区详解**：

```python
# 误区：用收入算 LTV
错误做法 = {
    "公式": "LTV = 1000元/月 × 24个月 = 24,000元",
    "问题": "忽略了成本"
}

正确做法 = {
    "公式": "LTV = 1000元/月 × 70%毛利率 × 24个月 = 16,800元",
    "差异": "24,000 - 16,800 = 7,200元（高估43%！）"
}

print("为什么必须用毛利而不是收入？")
print(f"错误示范：{错误做法['公式']}")
print(f"正确计算：{正确做法['公式']}")
print(f"差异：{正确做法['差异']}")
print("\n后果：误判商业模式健康度，过度投入获客预算，实际亏损却以为盈利")
```

## 总结

| 内容 | 要点 |
|-----|------|
| LTV | 用户生命周期价值，用**毛利**计算，不是收入 |
| CAC | 获客成本，包含广告+人力+工具+活动+佣金 |
| 健康判断 | LTV/CAC ≥ 3 健康，< 1 亏损 |
| 回报周期 | CAC ÷ 月均毛利，理想 < 12个月 |
| 最高杠杆 | 降低流失率比降低 CAC 效果更大 |
| 常见误区 | 用收入算 LTV、CAC 只算广告费、用均值掩盖分布 |
