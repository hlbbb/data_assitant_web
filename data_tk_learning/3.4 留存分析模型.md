## 一、什么是留存分析？

### 1.1 用生活例子理解

**用生活例子理解**：

留存分析就像"开餐厅看回头客"：

- 发传单拉客人进店 → 这就是获客（Acquisition）
- 客人吃完后还会不会再来 → 这就是留存（Retention）

```python
# 餐厅经营的两种模式对比
餐厅A = {
    "每天发传单": 1000张,
    "回头客比例": "5%",
    "结果": "每天都很忙,但赚不到钱 → 竹篮打水一场空"
}

餐厅B = {
    "每天新客": 50人,
    "回头客比例": "80%",
    "结果": "口碑积累,越做越大 → 健康增长"
}

print("核心结论：留不住的用户,获客再多也是竹篮打水")
print("留存率 = 某日回访用户数 / 首日新增用户数 × 100%")
```

**专业术语**：

留存分析是追踪用户在首次使用产品后,在后续时间段内持续回访的行为,是衡量产品长期价值的**最核心指标**。

### 1.2 留存率核心指标

| 指标 | 定义 | 计算公式 | 行业基准(社交) | 行业基准(电商) |
|------|------|---------|---------------|---------------|
| **D1留存** | 次日留存率 | D1回访用户/新增用户 | 40-55% | 25-35% |
| **D7留存** | 7日留存率 | D7回访用户/新增用户 | 20-35% | 12-20% |
| **D30留存** | 30日留存率 | D30回访用户/新增用户 | 10-20% | 5-15% |

### 1.3 为什么留存是最重要的指标？

**用生活例子理解**：

虚荣指标就像"餐厅门口排队的人多"——看起来很热闹,但如果排队的人吃完就再也不来,那这个热闹是虚假繁荣。

```python
# 虚荣指标 vs 核心指标
虚荣指标 = ["下载量", "注册量", "PV"]
# 问题: 用户来了就走,没有实际价值

核心指标 = ["留存率", "付费率", "NPS"]
# 价值: 用户持续使用,产生真实价值

# 留存对 LTV 的指数级影响
月流失率_5_percent = 0.05
月流失率_3_percent = 0.03

生命周期_5 = 1 / 月流失率_5_percent  # 20个月
生命周期_3 = 1 / 月流失率_3_percent  # 33个月

提升比例 = (生命周期_3 - 生命周期_5) / 生命周期_5

print(f"流失率从5%降至3%,留存率提升5%")
print(f"生命周期从{生命周期_5:.0f}个月延长到{生命周期_3:.0f}个月")
print(f"LTV提升{提升比例:.0%}！")
```

## 二、留存分析三步法

### 2.1 三步法总览

| 步骤 | 核心任务 | 关键问题 | 输出成果 |
|:----:|:--------:|:--------:|:--------:|
| **Step 1** | 定义留存 | 什么是"活跃"？ | 活跃定义文档 |
| **Step 2** | 计算留存率 | 留存曲线是什么形状？ | 留存曲线图 |
| **Step 3** | 分析并优化 | 哪里流失最严重？如何优化？ | 优化策略方案 |

### 2.2 Step 1：定义"留存"

**用生活例子理解**：

留存定义就像"什么算回头客"——是"进店就算"还是"必须点菜才算"？定义不同,数据含义完全不同。

```python
# 不同产品的"活跃"定义
活跃定义 = {
    "社交APP": "发消息或刷动态（核心行为）",
    "电商APP": "浏览商品或下单（购物行为）",
    "工具APP": "使用核心功能（解决问题）",
    "内容APP": "浏览内容≥30秒（真正消费）"
}

# 常见错误定义
错误定义 = {
    "定义太宽": "打开APP就算活跃 → 留存率虚高",
    "定义太窄": "必须付费才算活跃 → 留存率过低",
    "定义不一致": "每次改定义 → 无法对比"
}

print("关键原则：留存定义要与产品的核心价值对齐")
print("不是简单的'打开APP',而是'完成核心行为'")
```

### 2.3 Step 2：计算留存率

```python
# 留存率计算示例
新增用户 = 10000
次日回访 = 4800
第7日回访 = 2500
第30日回访 = 1200

D1留存 = 次日回访 / 新增用户
D7留存 = 第7日回访 / 新增用户
D30留存 = 第30日回访 / 新增用户

print(f"D1留存：{D1留存:.0%}")
print(f"D7留存：{D7留存:.0%}")
print(f"D30留存：{D30留存:.0%}")

# 判断健康度
行业基准_社交 = {"D1": 0.45, "D7": 0.28, "D30": 0.15}

if D1留存 >= 行业基准_社交["D1"]:
    print("D1留存：高于行业基准 ✓")
else:
    print("D1留存：低于行业基准 ⚠️")
```

### 2.4 Step 3：留存曲线分析

**用生活例子理解**：

留存曲线就像"淘金"——刚开始沙子很多,快速流失；淘到一定程度,剩下的都是金子,不会再流失了。这个转折点就是"拐点"。

```python
# 留存曲线数据
留存曲线 = {
    "D0": 100, "D1": 48, "D2": 40, "D3": 35,
    "D5": 28, "D7": 25, "D14": 19, "D21": 15,
    "D30": 12, "D60": 8
}

print("留存曲线分析：")
for 天数, 留存率 in 留存曲线.items():
    print(f"{天数}：{留存率}%")

# 计算日衰减率
def 计算衰减率(今日留存, 昨日留存):
    return (昨日留存 - 今日留存) / 昨日留存 * 100

D1衰减 = 计算衰减率(48, 100)  # -52%
D7衰减 = 计算衰减率(25, 28)   # -10.7%
D30衰减 = 计算衰减率(12, 15)  # -20%

print(f"\nD1衰减率：{D1衰减:.1f}%（最大流失点）")
print(f"D7衰减率：{D7衰减:.1f}%（拐点出现）")
print(f"D30衰减率：{D30衰减:.1f}%（趋于稳定）")
```

### 2.5 留存曲线四种类型

| 曲线类型 | 形状特征 | 健康度 | 典型产品 | 策略建议 |
|---------|---------|:------:|---------|---------|
| **快速稳定型** | 快速下降后平稳 | ★★★★★ | 微信、抖音 | 扩大核心用户群 |
| **缓慢衰减型** | 持续缓慢下降 | ★★★★☆ | 电商、工具 | 提升使用频次 |
| **持续下降型** | 无拐点,持续流失 | ★★☆☆☆ | 问题产品 | 重新审视PMF |
| **断崖下跌型** | 首日后急剧流失 | ★☆☆☆☆ | 严重问题 | 立即优化新手引导 |

## 三、实战案例：内容APP留存分析

### 3.1 业务背景

> 某内容APP 3个月累计注册50万用户,但DAU增长放缓。需要深入分析留存情况,找到优化方向。

### 3.2 整体留存分析

```python
# 3月新用户留存数据
留存数据 = {
    "D1": 48, "D3": 35, "D7": 25,
    "D14": 19, "D21": 15, "D30": 12, "D60": 8
}

行业基准 = {
    "D1": (40, 55),  # 范围
    "D7": (20, 35),
    "D30": (10, 20)
}

print("留存率对标分析：")
for 指标, 实际值 in 留存数据.items():
    if 指标 in 行业基准:
        下限, 上限 = 行业基准[指标]
        if 实际值 >= 下限 and 实际值 <= 上限:
            状态 = "正常 ✓"
        elif 实际值 > 上限:
            状态 = "优秀 ★"
        else:
            状态 = "偏低 ⚠️"
        print(f"{指标}：{实际值}%，行业基准{下限}-{上限}%，{状态}")
```

### 3.3 同期群分析

**用生活例子理解**：

同期群分析就像追踪"不同年份入学的学生"的毕业率——2020年入学的学生4年后毕业率是多少？2021年入学的呢？对比不同批次的表现差异。

```python
# 同期群留存数据
同期群 = {
    "1月": {"新增": 80000, "D1": 42, "D7": 22, "D30": 10},
    "2月": {"新增": 100000, "D1": 45, "D7": 23, "D30": 11},
    "3月": {"新增": 120000, "D1": 48, "D7": 25, "D30": 12},
    "4月": {"新增": 150000, "D1": 46, "D7": 24, "D30": None},
    "5月": {"新增": 160000, "D1": 50, "D7": 27, "D30": None}
}

print("同期群留存对比：")
for 月份, 数据 in 同期群.items():
    D30显示 = f"{数据['D30']}%" if 数据['D30'] else "—"
    print(f"{月份}：D1 {数据['D1']}%，D7 {数据['D7']}%，D30 {D30显示}")

# 趋势判断
D1趋势 = [数据["D1"] for 数据 in 同期群.values() if 数据["D1"]]
print(f"\nD1留存趋势：{D1趋势}")
print("结论：整体呈上升趋势，3月同期群表现最好")
```

### 4.3 回流分析

**用生活例子理解**：

回流分析就像餐厅的"回头客"——有的客人每周都来（连续活跃），有的客人几个月不来突然又来了（回流）。回流的客人也是餐厅的宝贵资产。

```python
# 月度回流数据
月度数据 = {
    "活跃用户": 180000,
    "留存用户": 150000,  # 上月活跃本月仍活跃
    "回流用户": 30000    # 上月沉默本月回流
}

回流率 = 月度数据["回流用户"] / (月度数据["活跃用户"] - 月度数据["留存用户"] + 月度数据["回流用户"])
回流占比 = 月度数据["回流用户"] / 月度数据["活跃用户"]

print(f"回流率：{回流率:.0%}（沉默用户中有{回流率:.0%}回流）")
print(f"回流用户占比：{回流占比:.0%}")

# 沉默时长 vs 回流率
沉默回流 = {
    "1-7天": 35, "8-14天": 25, "15-30天": 15,
    "31-60天": 8, "60-90天": 3, "90天以上": 1
}

print("\n沉默时长 vs 回流率：")
for 时长, 回流率 in 沉默回流.items():
    标记 = "★ 黄金期" if 回流率 >= 25 else ""
    print(f"{时长}：{回流率}% {标记}")

print("\n策略：沉默7天内推送召回消息效果最好")
```

## 五、常见误区与纠正

| 误区 | 表现 | 后果 | 纠正方法 | 生活类比 |
|------|------|------|----------|----------|
| **定义太宽** | "打开APP"算留存 | 留存率虚高，掩盖问题 | 用核心行为定义留存 | 只进店不算回头客，要点菜才算 |
| **只看整体不分群** | 所有用户混在一起 | 无法发现高/低留存群体 | 按渠道、行为分层看 | 平均身高1.7米，但有人1.5米有人1.9米 |
| **样本量不足** | 50个用户也算留存 | 结论不可靠 | 样本量≥500才统计 | 问2个人不能代表全班意见 |
| **忽略回流** | 只看连续活跃 | 低估真实粘性 | 同时统计回流率 | 回头客不一定是每周都来的 |
| **不与行业对标** | "留存25%是好是坏？" | 无法判断健康度 | 必须与行业基准对比 | 60分是好是坏？要看平均分 |

**最常见误区详解**：

```python
# 误区：定义太宽
错误定义 = "打开APP就算活跃"
错误后果 = {
    "D1留存": "70%（虚高）",
    "问题": "误触、推送打开都算活跃",
    "结果": "掩盖了真实的产品问题"
}

正确做法 = {
    "内容APP": "浏览内容≥30秒",
    "社交APP": "发送消息≥1条",
    "电商APP": "浏览商品详情页≥1个"
}

print("为什么要用核心行为定义留存？")
print(f"错误定义：{错误定义}")
print(f"后果：{错误后果['D1留存']}，{错误后果['问题']}")
print("\n正确做法：")
for 产品类型, 定义 in 正确做法.items():
    print(f"  {产品类型}：{定义}")
```
