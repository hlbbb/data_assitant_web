## 一、什么是A/B测试？

### 1.1 用生活例子理解

**用生活例子理解**：

A/B测试就像"药物临床试验"——想知道新药是否有效，不能只看"吃药的人都康复了"（可能是他们本身体质好）。正确做法是随机分两组：一组吃药，一组吃糖丸（对照），对比康复率差异。

```python
# 药物试验类比
药物试验类比 = {

        "方法": "只观察吃药的人",

        "结论": "无法判断是药有效还是体质好"
    },
    "正确做法（A/B测试）": {
```

**专业术语**：

A/B测试是通过**随机对照实验**验证因果关系的决策工具：将用户随机分为对照组（A）和实验组（B），对比单一变量差异，用统计检验判断效果是否显著。

### 1.3 三大因果推断方法对比

| 方法 | 原理 | 局限性 | 适用场景 |
|------|------|--------|----------|
| **A/B测试** | 随机分配，切断混淆变量路径 | 无法测试已上线内容 | 新功能、策略变更 |
| **DID（双重差分）** | 找一个"平行趋势"的对照组 | 平行假设难验证 | 政策评估、自然实验 |
| **PSM（倾向匹配）** | 用统计方法模拟随机化 | 无法控制未观测变量 | 回顾性数据分析 |

## 二、统计基础概念

### 2.1 核心概念速查表

| 概念 | 含义 | 生活化理解 | 典型值 |
|------|------|-----------|--------|
| **H0（原假设）** | 两组无差异 | 假设"新按钮没效果" | — |
| **H1（备择假设）** | 两组有差异 | "新按钮确实有效果" | — |
| **α（显著性水平）** | 犯第一类错误概率 | 把无效当有效的风险 | 0.05 |
| **β** | 犯第二类错误概率 | 把有效当无效的风险 | 0.2 |
| **统计功效 1-β** | 正确拒绝H0的概率 | 有效时能检测出来的概率 | ≥0.8 |
| **MDE** | 最小可检测效应 | 能检测出的最小差异 | 业务定义 |
| **p值** | 结果偶然出现的概率 | p<0.05才算"真的有效" | <0.05 |
| **置信区间** | 真实效果的估计范围 | "95%CI不含0则显著" | — |

### 2.2 第一类错误 vs 第二类错误

```python

for 错误, 信息 in 错误类型.items():

    print(f"  含义：{信息['含义']}")

```

### 2.3 样本量计算公式

```python
# 样本量计算
import math

def 计算样本量(基线转化率, MDE, alpha=0.05, power=0.8):
    """
    计算A/B测试每组所需样本量
    基线转化率: 对照组转化率 (如 0.08)
    MDE: 最小可检测差异 (如 0.02)
    alpha: 显著性水平 (默认 0.05)
    power: 统计功效 (默认 0.8)
    """
    Z_alpha = 1.96  # α=0.05双侧检验
    Z_beta = 0.84   # 功效=0.8
    
    n = (Z_alpha + Z_beta)**2 * 2 * 基线转化率 * (1 - 基线转化率) / MDE**2
    
    return math.ceil(n)

# 示例计算
基线 = 0.08  # 8%转化率
MDE = 0.02   # 检测2个百分点差异

样本量 = 计算样本量(基线, MDE)

print("样本量计算示例：")
print(f"  基线转化率：{基线*100:.0f}%")
print(f"  MDE：{MDE*100:.0f}%（想检测至少{MDE*100:.0f}个百分点差异）")
print(f"  每组所需样本量：{样本量}人")
print(f"  总样本量：{样本量*2}人（两组合计）")

print("\n关键规律：样本量与MDE的平方成反比")
print("  • 想检测一半的差异 → 需要4倍样本")
print("  • 想检测更小的效果 → 样本量呈平方级增长")
```

### 3.2 决策判断逻辑

```python
# 决策判断函数
def 实验决策(p值, 置信区间下限, MDE):
    """
    根据实验结果做出决策
    """
    统计显著 = p值 < 0.05 and 置信区间下限 > 0
    业务显著 = 置信区间下限 >= MDE
```

### 4.2 实验数据与统计检验

```python
# 实验数据
对照组 = {"样本量": 2886, "转化人数": 231}
实验组 = {"样本量": 2886, "转化人数": 281}

对照组["转化率"] = 对照组["转化人数"] / 对照组["样本量"]
实验组["转化率"] = 实验组["转化人数"] / 实验组["样本量"]

print("实验数据：")
print(f"{'指标':<15} {'对照组A（绿色）':<20} {'实验组B（红色）'}")
print("-" * 50)
print(f"{'样本量':<15} {对照组['样本量']:<20} {实验组['样本量']}")
print(f"{'转化人数':<15} {对照组['转化人数']:<20} {实验组['转化人数']}")
print(f"{'转化率':<15} {对照组['转化率']*100:.2f}%{'':<15} {实验组['转化率']*100:.2f}%")

差异 = 实验组["转化率"] - 对照组["转化率"]
print(f"{'差异':<15} {'—':<20} +{差异*100:.2f}pp")

# Z检验
混合转化率 = (对照组["转化人数"] + 实验组["转化人数"]) / (对照组["样本量"] + 实验组["样本量"])
标准误 = math.sqrt(混合转化率 * (1 - 混合转化率) * (1/对照组["样本量"] + 1/实验组["样本量"]))
Z值 = 差异 / 标准误

print(f"\n统计检验：")
print(f"  Z值：{Z值:.2f}")
print(f"  判断：Z > 1.96 → p < 0.05 → 统计显著")
print(f"  结论：红色按钮转化率显著更高")
```

### 4.3 置信区间计算

```python
# 置信区间计算
置信区间下限 = 差异 - 1.96 * 标准误
置信区间上限 = 差异 + 1.96 * 标准误

print("置信区间解读：")
print(f"  转化率差异：+{差异*100:.2f}pp")
print(f"  95%置信区间：[{置信区间下限*100:.2f}%, {置信区间上限*100:.2f}%]")

print("\n置信区间含义：")
print(f"  • 区间不含0 → 统计显著 ✓")
print(f"  • 下限{置信区间下限*100:.2f}% > 0 → 真正有提升 ✓")
print(f"  • 上限{置信区间上限*100:.2f}% → 最乐观情况提升{置信区间上限*100:.2f}pp")

if 置信区间下限 >= 0.02:
    print(f"  • 下限 ≥ MDE(2%) → 业务显著 ✓")
else:
    print(f"  • 下限 < MDE(2%) → 业务需谨慎 ⚠️")
```

## 五、常见陷阱识别

### 5.1 陷阱速查表

| 陷阱名称 | 典型表现 | 根本原因 | 纠正方法 |
|---------|---------|---------|---------|
| **偷看(p-hacking)** | 多次检验直到显著 | 多重检验增加假阳性 | 预注册假设，一次检验 |
| **辛普森悖论** | 分组显著但合并后反转 | 混淆变量影响 | 分层分析，检查混淆 |
| **网络效应** | 用户间相互影响 | 实验单元不独立 | 隔离实验单元或时间片实验 |
| **新奇效应** | 短期有效长期失效 | 用户对新事物好奇 | 延长周期，监控长期指标 |
| **样本量不足** | 统计功效不够 | 提前计算错误 | 提前计算，确保n足够 |
| **SRM偏差** | 分流比例与预期不符 | 分流算法bug | 检验分流，修复日志 |
| **多重比较** | 多指标多组导致假阳性 | 未校正α | Bonferroni/FDR校正 |

## 七、常见误区与纠正

| 陷阱 | 表现 | 后果 | 纠正方法 | 生活类比 |
|------|------|------|----------|----------|
| **偷看** | 多次检验直到显著 | 假阳性率飙升 | 预注册假设，一次检验 | 每天买彩票中了说运气好 |
| **辛普森悖论** | 分层显著但合并反转 | 错误决策 | 分层分析，检查混淆 | 两个班级都进步但全校退步 |
| **网络效应** | 用户间相互影响 | 效果被稀释 | 隔离实验单元 | 疫情传播无法单独隔离 |
| **新奇效应** | 短期有效长期失效 | 上线后效果消失 | 延长周期监控长期 | 新玩具玩两天就不玩了 |
| **样本量不足** | 统计功效不够 | 错过真实效果 | 提前计算确保n足够 | 只问3个人就下结论 |
| **SRM偏差** | 分流比例与预期不符 | 两组不可比 | 检验分流修复bug | 抽签发现签筒有问题 |
| **多重比较** | 多指标导致假阳性 | 错误上线 | Bonferroni校正 | 猜100次总有猜对的 |

## 总结

| 内容 | 要点 |
|-----|------|
| A/B测试本质 | 随机对照实验验证因果关系 |
| 核心概念 | H0/H1、α(0.05)、β(0.2)、功效(≥0.8)、MDE、p值 |
| 样本量公式 | n ≈ 16 × p(1-p) / δ² |
| 六步流程 | 确定假设→计算样本→随机分流→运行实验→统计检验→决策上线 |
| 决策标准 | 统计显著(p<0.05) + 业务显著(效果≥MDE) → 上线 |
| 常见陷阱 | 偷看、辛普森悖论、网络效应、新奇效应、SRM偏差、多重比较 |
| 进阶用法 | Bandit算法、多重比较校正、MVT多变量测试 |
