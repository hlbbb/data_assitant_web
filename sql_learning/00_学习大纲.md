# SQL 从零到精通学习大纲

> **写给新手的你**：这份教程不是干巴巴的语法手册，而是带你从"SQL是啥"到"能写复杂分析"的实战路线。每个阶段都有真实案例、常见坑点、还有接地气的比喻。别怕，咱们一步步来。

---

## 🎯 学习路线图

```
基础入门 → 聚合分组 → 多表连接 → 子查询CTE → 窗口函数 → 数据操作 → 高级技巧 → 实战项目
   ↓          ↓          ↓          ↓          ↓          ↓          ↓          ↓
  2天        2天        3天        3天        5天        3天        4天        5天
```

**总学习时长**：约27天（每天2-3小时）

## 📋 各阶段详解

### 第一阶段：基础入门（预计2天）

**为什么从这开始**：这是SQL的地基。地基打不牢，后面学窗口函数、子查询都会晕。

**核心技能**：
- SELECT / FROM 基础查询
- WHERE 条件过滤
- AND / OR / NOT 逻辑运算
- ORDER BY 排序
- LIMIT 限制结果数量
- DISTINCT 去重
- NULL 值处理

**学完你能做**：
- 从数据库里查出想要的数据
- 筛选符合条件的数据
- 按指定顺序排列结果

**新手常见坑**：
- WHERE里用`=` NULL（错！要用IS NULL）
- ORDER BY忘记写ASC/DESC，结果顺序乱
- LIMIT和OFFSET搞混

**前置准备**：
- 安装SQLite或MySQL（本教程用SQLite，轻量免安装）
- 下载练习数据集（employees.db）

---

### 第二阶段：聚合与分组（预计2天）

**为什么学这个**：做数据分析必须掌握。COUNT、SUM、AVG这些函数能帮你快速统计"有多少""总共多少""平均多少"。

**核心技能**：
- 聚合函数 COUNT / SUM / AVG / MAX / MIN
- GROUP BY 分组聚合
- HAVING 分组后过滤
- 聚合函数与 NULL 的交互

**学完你能做**：
- 统计各部门人数、平均薪资
- 找出销售额最高的前10个产品
- 计算用户留存率的基础数据

**新手常见坑**：
- GROUP BY后SELECT了非聚合列（报错！）
- HAVING和WHERE用混了
- COUNT(*)和COUNT(列)的区别不清楚

---

### 第三阶段：多表连接（预计3天）

**为什么学这个**：真实业务中数据分散在多张表，JOIN是连接它们的桥梁。不会JOIN，寸步难行。

**核心技能**：
- INNER JOIN / LEFT JOIN / RIGHT JOIN / FULL OUTER JOIN
- CROSS JOIN / SELF JOIN
- 连接条件 vs 过滤条件

**学完你能做**：
- 查询"员工所属部门名称"（员工表+部门表）
- 找出"没有订单的用户"（LEFT JOIN + WHERE IS NULL）
- 分析"用户购买路径"（多表串联）

**新手常见坑**：
- ON和WHERE分不清，结果数据不对
- LEFT JOIN后过滤条件写错位置，变成INNER JOIN效果
- 多表连接忘记加表别名，列名冲突

---

### 第四阶段：子查询与CTE（预计3天）

**为什么学这个**：有些问题一步查不出来，需要"先查一步，再查一步"。子查询和CTE就是干这个的。

**核心技能**：
- 标量子查询 / 列子查询
- EXISTS / NOT EXISTS
- CTE（WITH 子句）
- 递归 CTE

**学完你能做**：
- 找出"薪资高于部门平均的员工"
- 查询"组织架构树"（递归CTE）
- 简化复杂嵌套查询（用CTE替代多层子查询）

**新手常见坑**：
- 子查询返回多行但用了单行比较符
- EXISTS和IN用混了，性能差
- CTE忘记逗号分隔，语法报错

---

### 第五阶段：窗口函数 ⭐（预计5天）

**为什么学这个**：这是SQL的"核武器"。掌握窗口函数，你能解决90%的数据分析难题。排序、累计、同比环比、留存分析，全靠它。

**核心技能**：
- ROW_NUMBER / RANK / DENSE_RANK
- LEAD / LAG
- 窗口聚合与 PARTITION BY
- ROWS BETWEEN 滑动窗口

**学完你能做**：
- 计算每个用户的消费排名（ROW_NUMBER）
- 找出每个部门薪资前3名（PARTITION BY + RANK）
- 计算月环比增长率（LAG）
- 计算移动平均（ROWS BETWEEN）

**新手常见坑**：
- PARTITION BY和GROUP BY搞混
- ROWS BETWEEN边界写错，结果不对
- RANK和DENSE_RANK的区别不清楚

**重点提示**：这个阶段是整个教程的精华，务必多练！

---

### 第六阶段：数据操作与建表（预计3天）

**为什么学这个**：前面都是查数据，这个阶段教你改数据、建表。做数据清洗、数据迁移必须掌握。

**核心技能**：
- INSERT / UPDATE / DELETE
- CREATE TABLE 与数据类型
- 约束与索引
- 事务基础

**学完你能做**：
- 创建自己的数据表
- 批量插入、更新、删除数据
- 设置主键、外键、唯一约束
- 用事务保证数据一致性

**新手常见坑**：
- UPDATE忘记写WHERE，全表被改
- DELETE忘记写WHERE，全表被删
- 外键约束导致插入失败

---

### 第七阶段：高级分析技巧（预计4天）

**为什么学这个**：真实业务场景千奇百怪，光会基础语法不够。这个阶段教你"花式操作"。

**核心技能**：
- CASE WHEN 条件逻辑
- 日期函数与时间序列分析
- 数据透视（行转列 / 列转行）

**学完你能做**：
- 用CASE WHEN做数据分类（如：年龄段分组）
- 计算同比、环比、留存率
- 把行数据转成列（透视表效果）

**新手常见坑**：
- CASE WHEN忘记END
- 日期函数格式符记不住
- 行转列逻辑绕晕

---

### 第八阶段：实战项目（预计5天）

**为什么学这个**：理论学了一堆，不实战永远记不住。这4个项目覆盖电商、财务、用户增长、A/B测试，都是真实业务场景。

**核心技能**：
- 电商用户行为分析
- 留存率分析
- A/B 测试分析

**学完你能做**：
- 独立完成一个完整的数据分析项目
- 从建表、清洗、分析到输出报告
- 面试时拿出真实项目经验

**项目列表**：
1. **电商用户行为分析**：分析用户浏览、加购、下单转化漏斗
2. **财务月报**：自动生成月度收入、成本、利润报表
3. **留存率分析**：计算次日、7日、30日留存率
4. **A/B测试分析**：判断实验组是否显著优于对照组

## 🛠️ 学习建议

### 新手必读

1. **别只看不练**：每个案例都要自己敲一遍，运行一遍
2. **先理解再背**：理解了原理，语法自然就记住了
3. **遇到报错别慌**：报错信息是最好的老师，读懂它
4. **善用注释**：复杂SQL一定要写注释，方便以后回顾

### 学习节奏建议

- **每天2-3小时**：不要贪多，消化比速度重要
- **每学完一个阶段**：做几道练习题巩固
- **遇到卡点**：先自己查资料，实在不行再看答案
- **学完所有阶段后**：重做一遍实战项目，检验掌握程度

### 推荐学习工具

- **在线练习**：本教程配套SQL练习环境（网页直接运行）
- **本地环境**：DB Browser for SQLite（可视化工具）
- **参考手册**：SQLite官方文档（https://www.sqlite.org/lang.html）
