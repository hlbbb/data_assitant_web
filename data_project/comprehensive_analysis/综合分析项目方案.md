# 综合分析项目方案：跨境电商「数据驱动增长」全案诊断

> **项目类型：** 综合分析实战（融合多种思维模型）
> **项目定位：** 模拟真实工作中的年度数据复盘场景
> **图表数量：** 15~18 张
> **产出物：** 核心脚本 + 可视化 + 分析报告 + 深度剖析 + PPT

---

## 一、业务场景

### 1.1 公司背景

**公司A** 是一家面向东南亚市场的跨境电商平台，2023年1月正式运营，至2024年12月已运营 24 个月。平台覆盖泰国、越南、印尼、菲律宾、马来西亚五国，主营美妆、3C数码、服饰、家居、食品五个品类。

### 1.2 业务现状

- 24 个月累计注册用户约 8,000 人，总交易额约 1,500 万元
- 覆盖 5 个国家、5 个品类、5+ 个获客渠道
- 用户增长进入平台期，获客成本持续上升
- 部分国家市场表现优异，部分国家持续亏损

### 1.3 触发事件

公司A 即将进入第二轮融资，投资人要求提交一份**全面增长诊断报告**，核心诉求：

1. **钱花得值不值？** — 各渠道/各国家的投入产出比
2. **用户为什么来、为什么走？** — 留存与流失的根因
3. **增长引擎在哪？** — 下一阶段的战略方向和资源配置建议

## 二、分析框架设计

### 2.1 思维模型选型

基于《数据分析思维模型全攻略》，本项目综合运用以下模型：

| 层级 | 选用模型 | 用途 |
|------|---------|------|
| L1 基础思维 | **结构化思维（MECE）** | 将"增长"拆解为获客、留存、变现、传播四个子问题 |
| L1 基础思维 | **漏斗思维** | 定位用户旅程中的流失断点 |
| L1 基础思维 | **对比思维** | 分国家/渠道/品类的横向对比 |
| L1 基础思维 | **分类思维** | 用户价值分层、市场成熟度分类 |
| L2 分析模型 | **描述性分析** | 趋势、分布、构成——全景概览 |
| L2 分析模型 | **诊断性分析** | 异常检测、5 Whys 根因分析 |
| L3 商业模型 | **RFM** | 用户价值分层（按国家维度细分） |
| L3 商业模型 | **AARRR** | 增长漏斗（按渠道×国家交叉拆解） |
| L3 商业模型 | **LTV/CAC** | 渠道与国家的ROI评估 |
| L3 商业模型 | **同期群分析（Cohort）** | 留存衰减规律、LTV增长曲线 |
| L4 方法论 | **DMAIC** | Define→Measure→Analyze→Improve→Control 全流程 |
| L4 方法论 | **OSM 模型** | 北极星指标 → 策略 → 度量的指标体系 |

### 2.2 分析主线

```
DMAIC 框架驱动：
├── Define  → 定义北极星指标：月度GMV × 活跃用户数
├── Measure → 5张表全景数据采集 + KPI仪表盘
├── Analyze → 三条分析主线（见下）
├── Improve → 策略建议 + 资源优化方案
└── Control → 监控指标体系 + 行动路线图

三条分析主线：
├── 增长线：AARRR漏斗 → 渠道效率 → LTV/CAC
├── 价值线：RFM分层 → 用户价值 → 帕累托效应
└── 市场线：分国家对比 → 品类结构 → 市场成熟度
```

## 三、数据源设计（5张核心表）

### 3.1 `users.csv` — 用户画像表（~8,000条）

| 字段 | 说明 | 取值 |
|------|------|------|
| user_id | 用户ID | U00001~U08000 |
| register_date | 注册日期 | 2023-01 ~ 2024-12 |
| country | 所在国家 | 泰国/越南/印尼/菲律宾/马来西亚 |
| channel | 获客渠道 | 自然搜索/付费广告/社交媒体/KOL推荐/内容营销 |
| device | 设备类型 | iOS/Android |
| age_group | 年龄段 | 18-24/25-34/35-44/45+ |
| gender | 性别 | 男/女 |

**模拟要点：**
- 各国注册量不均：泰国和印尼用户最多，马来西亚最少
- 渠道分布随时间变化：早期依赖付费广告，后期自然流量增加
- 年龄和性别按各国人口结构分配

### 3.2 `transactions.csv` — 交易明细表（~30,000条）

| 字段 | 说明 | 取值 |
|------|------|------|
| user_id | 用户ID | — |
| order_id | 订单ID | — |
| order_date | 下单日期 | 2023-01 ~ 2024-12 |
| order_amount | 订单金额 | 10~3000元（各国消费力不同） |
| category | 品类 | 美妆/3C数码/服饰/家居/食品 |
| country | 下单国家 | — |
| is_first_order | 是否首单 | True/False |

**模拟要点：**
- 用户分四档（鲸鱼5%/海豚15%/小鱼30%/虾米50%）
- 各国客单价差异：泰国和马来西亚较高，越南和菲律宾较低
- 品类偏好差异：印尼偏好食品和美妆，泰国偏好3C和服饰

### 3.3 `user_events.csv` — 用户行为事件表（~60,000条）

| 字段 | 说明 | 取值 |
|------|------|------|
| user_id | 用户ID | — |
| event_type | 事件类型 | register/app_open/browse/add_to_cart/purchase/repurchase/share |
| event_date | 事件日期 | — |
| page_id | 页面ID | home/product/category/cart/checkout 等 |
| duration_seconds | 停留时长 | 5~600秒 |

### 3.4 `channel_costs.csv` — 渠道成本表

| 字段 | 说明 |
|------|------|
| channel | 渠道名称 |
| country | 国家 |
| monthly_budget | 月度预算 |
| cost_per_user | 单用户获客成本 |

**模拟要点：**
- 付费广告CAC最高（各国不同：泰国¥40，越南¥25）
- KOL推荐CAC中等但各国差异大
- 内容营销CAC最低但规模有限

### 3.5 `user_feedback.csv` — 用户评价表（~12,000条）

| 字段 | 说明 | 取值 |
|------|------|------|
| user_id | 用户ID | — |
| order_id | 订单ID | — |
| rating | 评分 | 1~5 |
| feedback_text | 评价文本 | 正面/中性/负面评价（模拟） |
| feedback_date | 评价日期 | — |
| category | 评价品类 | — |

**模拟要点：**
- 评分分布：5星(35%) 4星(30%) 3星(20%) 2星(10%) 1星(5%)
- NPS估算：推荐者(9-10分) - 贬损者(0-6分)
- 各国满意度有差异：泰国最高，菲律宾最低

## 八、与前序项目的关系

### 8.1 模型融合关系

本项目**不是重复做 RFM/AARRR/LTV**，而是将它们作为**子模块融入一个完整的业务诊断框架**中：

| 前序项目 | 本项目中的定位 | 新增维度 |
|---------|-------------|---------|
| RFM | 第4章用户分层 | 按国家维度细分RFM，增加国际视角 |
| AARRR | 第3章增长漏斗 | 按渠道×国家交叉拆解，更细粒度 |
| LTV/CAC | 第5章渠道ROI | 按国家×渠道二维ROI矩阵 |
| **新增** | 分国家市场对比 | 雷达图+成熟度矩阵——全新分析维度 |
| **新增** | 品类与复购 | 关联分析+复购周期——全新分析维度 |
| **新增** | 满意度与流失 | NPS+流失归因——全新分析维度 |
| **新增** | DMAIC框架 | 端到端分析流程——方法论整合 |

### 8.2 新增能力

对比前三个项目，本项目的进阶点：

| 维度 | 前序项目 | 本项目 |
|------|---------|-------|
| 数据规模 | 1~2张表 | **5张表**，关联关系更复杂 |

## 十、关键技术点

### 10.1 新增技术挑战

- **多表关联分析**：5张表通过 user_id/order_id 关联，需要 merge/join 操作
- **跨国对比分析**：需要按 country 维度分组，处理各国数据量不均衡
- **品类关联分析**：计算共购矩阵（用户同时购买A和B的概率）
- **NPS计算**：推荐者(%) - 贬损者(%)
- **雷达图绘制**：多维度归一化后绘制

### 10.2 数据模拟要点

- 各国用户量差异（印尼/泰国多，马来西亚少）
- 各国消费力差异（反映在客单价上）
- 渠道效果因国家而异（KOL在印尼效果好，搜索在泰国好）
- 品类偏好因国家而异
- 评分因国家/品类而异
