## 一、逆透视(Pivot/Unpivot)

### 什么是逆透视?

**透视** = 把行变成列

**逆透视** = 把列变成行

---

### 场景: 宽表转长表

假设你拿到一份这样的销售数据:

**原始数据(宽表)**:
```
产品名称    一月    二月    三月
iPhone     10000   12000   15000
MacBook    8000    9000    10000
```

这种格式不适合 Power BI 分析,需要转换成:

**目标数据(长表)**:
```
产品名称    月份    销售额
iPhone     一月    10000
iPhone     二月    12000
iPhone     三月    15000
MacBook    一月    8000
MacBook    二月    9000
MacBook    三月    10000
```

---

### 操作步骤

**步骤 1**: 导入数据

**步骤 2**: 进入 Power Query

**步骤 3**: 选中需要逆透视的列(一月、二月、三月)

**步骤 4**: 转换 → 逆透视列

**步骤 5**: 重命名生成的列
- "属性" → "月份"
- "值" → "销售额"

---

### 练习

创建一个测试文件,练习逆透视操作。

## 二、条件列

### 什么是条件列?

**条件列** = 根据条件生成新列

类似 Excel 的 IF 函数。

---

### 场景: 客户等级判断

根据消费金额判断客户等级:
- 金额 >= 10000 → "VIP客户"
- 金额 >= 5000 → "重要客户"
- 其他 → "普通客户"

---

### 操作步骤

**步骤 1**: 进入 Power Query

**步骤 2**: 添加列 → 条件列

**步骤 3**: 设置条件:
```
列名: 金额
运算符: 大于或等于
值: 10000
输出: VIP客户
```

**步骤 4**: 添加其他条件:
```
否则如果: 金额 >= 5000
输出: 重要客户

否则: 普通客户
```

**步骤 5**: 点击确定

---

### 生成的 M 代码

```m
= Table.AddColumn(源, "客户等级",
    each if [金额] >= 10000 then "VIP客户"
    else if [金额] >= 5000 then "重要客户"
    else "普通客户")
```

## 三、自定义列(M语言)

### 什么是自定义列?

**自定义列** = 用 M 语言写公式创建新列

比条件列更灵活,可以实现复杂计算。

---

### 常用 M 语言函数

| 函数 | 用途 | 例子 |
|------|------|------|
| Date.Year() | 提取年份 | `Date.Year([日期])` |
| Date.Month() | 提取月份 | `Date.Month([日期])` |
| Date.Day() | 提取日 | `Date.Day([日期])` |
| Text.Start() | 左边字符 | `Text.Start([姓名], 1)` |
| Text.End() | 右边字符 | `Text.End([姓名], 1)` |
| Text.Length() | 文本长度 | `Text.Length([姓名])` |
| Number.Round() | 四舍五入 | `Number.Round([金额], 2)` |

---

### 实例 1: 提取年月

**目标**: 从订单日期提取"年月"(如: 2024-01)

**操作**:
1. 添加列 → 自定义列
2. 输入公式:
```m
Text.From(Date.Year([订单日期])) & "-" & Text.PadStart(Text.From(Date.Month([订单日期])), 2, "0")
```

**解释**:
- `Date.Year([订单日期])` = 提取年份
- `Date.Month([订单日期])` = 提取月份
- `Text.From()` = 转成文本
- `Text.PadStart(..., 2, "0")` = 补零(1 → 01)
- `&` = 连接文本

**结果**: 2024-01, 2024-02, ...

---

### 实例 2: 计算利润

**目标**: 利润 = 金额 - 成本 × 数量

**问题**: 成本在产品表,不在销售表。

**解决**: 先合并查询,再计算。

## 四、合并查询

### 什么是合并查询?

**合并查询** = 把两个表按共同字段连接起来

类似 SQL 的 JOIN。

---

### 实例: 把产品成本合并到销售表

**目标**: 在销售表中显示产品的成本价

**操作**:

**步骤 1**: 进入 Power Query

**步骤 2**: 选择"销售事实表"

**步骤 3**: 开始 → 合并查询

**步骤 4**: 设置合并:
- 第一个表: 销售事实表
- 第二个表: 产品维度表
- 匹配字段: 产品ID

**步骤 5**: 选择联接类型:
- 左外部(Left Outer): 保留销售表所有行
- 推荐使用这个

**步骤 6**: 展开合并的列:
- 点击新列右侧的展开图标
- 只勾选"成本价"

**结果**: 销售表新增了"成本价"列

---

### 联接类型

| 类型 | 说明 | 适用场景 |
|------|------|----------|
| 左外部 | 保留左表所有行 | 最常用 |
| 右外部 | 保留右表所有行 | 较少用 |
| 完全外部 | 保留两表所有行 | 数据对比 |
| 内部 | 只保留匹配的行 | 数据清洗 |
| 左反 | 只保留不匹配的行 | 找缺失数据 |

---

## 五、追加查询

### 什么是追加查询?

**追加查询** = 把多个表的数据合并成一个表

类似 SQL 的 UNION。

---

### 场景: 合并多月数据

假设你每个月收到一个 CSV 文件:
- 2024-01销售.csv
- 2024-02销售.csv
- 2024-03销售.csv

需要合并成一个表。

---

### 操作步骤

**步骤 1**: 导入 3 个文件

**步骤 2**: 进入 Power Query

**步骤 3**: 开始 → 追加查询 → 将查询追加为新查询

**步骤 4**: 选择要追加的表:
- 第一个表: 2024-01销售
- 要追加的表: 2024-02销售, 2024-03销售

**步骤 5**: 点击确定

**结果**: 生成一个包含 3 个月数据的合并表

---

## 六、分组依据

### 什么是分组依据?

**分组依据** = 按某个字段分组,计算聚合值

类似 SQL 的 GROUP BY。

---

### 实例: 计算每个客户的总消费

**目标**: 生成客户消费汇总表

**操作**:

**步骤 1**: 进入 Power Query

**步骤 2**: 复制销售事实表(避免修改原表)

**步骤 3**: 开始 → 分组依据

**步骤 4**: 设置分组:
- 分组依据: 客户ID
- 新列名: 总消费
- 操作: 求和
- 列: 金额

**步骤 5**: 添加更多聚合:
- 订单数量: 计数
- 平均订单金额: 平均值

**结果**:
```
客户ID    总消费    订单数量    平均订单金额
C001      23992    4          5998
C002      21980    5          4396
...
```

## 八、M 语言简介

### 什么是 M 语言?

**M 语言** = Power Query 的脚本语言

你在 Power Query 做的每一步操作,都会生成 M 代码。

---

### 查看 M 代码

**步骤 1**: 进入 Power Query

**步骤 2**: 开始 → 高级编辑器

你会看到完整的 M 代码。

---

### M 语言基本结构

```m
let
    步骤1 = 操作1,
    步骤2 = 操作2,
    步骤3 = 操作3,
    ...
in
    最后结果
```

---

### 常用 M 函数

#### 数据类型转换
```m
Text.From(123)           // 数字转文本: "123"
Number.From("123")       // 文本转数字: 123
Date.From("2024-01-01")  // 文本转日期
```

#### 文本处理
```m
Text.Upper("abc")        // 转大写: "ABC"
Text.Lower("ABC")        // 转小写: "abc"
Text.Trim("  abc  ")     // 去空格: "abc"
Text.Split("a,b,c", ",") // 分割: {"a", "b", "c"}
Text.Contains("abc", "a") // 包含: true
```

#### 日期处理
```m
Date.Year(Date.From("2024-01-15"))    // 年: 2024
Date.Month(Date.From("2024-01-15"))   // 月: 1
Date.Day(Date.From("2024-01-15"))     // 日: 15
Date.AddDays(Date.From("2024-01-15"), 7)  // 加7天
```

## 十、常见问题

### Q1: 合并查询后数据变多了?

**原因**: 一对多关系,会复制多行

**解决**: 这是正常的,确保联接类型正确。

---

### Q2: 追加查询后列对不上?

**原因**: 两个表的列名或列数不同

**解决**: 确保两个表的结构一致,或者只选择相同的列。

---

### Q3: M 语言报错?

**原因**: 语法错误或字段名错误

**解决**:
- 检查字段名是否正确(区分大小写)
- 检查括号是否匹配
- 查看错误提示
