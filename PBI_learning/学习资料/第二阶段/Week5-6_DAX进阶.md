## 一、筛选上下文(核心概念)

### 什么是筛选上下文?

**筛选上下文** = 当前计算时生效的所有筛选条件

---

### 举个例子

假设你有一个度量值:
```dax
总销售额 = SUM('销售事实表'[金额])
```

**场景 1**: 没有任何筛选
- 筛选上下文 = 空
- 计算 = 所有销售额 = 147960

**场景 2**: 选择了"华北区"
- 筛选上下文 = 地区 = "华北区"
- 计算 = 华北区销售额 = 65980

**场景 3**: 选择了"iPhone"
- 筛选上下文 = 产品 = "iPhone"
- 计算 = iPhone销售额 = 59990

**关键点**: 同一个度量值,在不同上下文下计算结果不同。

---

### 理解 CALCULATE

**CALCULATE** = 修改筛选上下文

```dax
CALCULATE(表达式, 筛选条件1, 筛选条件2, ...)
```

**功能**:
- 先清除当前筛选上下文
- 应用新的筛选条件
- 执行表达式计算

## 二、时间智能函数

### 为什么需要时间智能函数?

**场景**: 计算去年同期销售额

**普通方法**(麻烦):
```dax
去年同期销售额 =
CALCULATE(
    SUM('销售事实表'[金额]),
    FILTER(
        ALL('日期维度表'),
        '日期维度表'[年份] = MAX('日期维度表'[年份]) - 1
    )
)
```

**时间智能函数**(简单):
```dax
去年同期销售额 =
CALCULATE(
    SUM('销售事实表'[金额]),
    SAMEPERIODLASTYEAR('日期维度表'[日期])
)
```

---

### 常用时间智能函数

| 函数 | 用途 | 例子 |
|------|------|------|
| SAMEPERIODLASTYEAR() | 去年同期 | 同比分析 |
| TOTALYTD() | 年初至今累计 | YTD分析 |
| TOTALMTD() | 月初至今累计 | MTD分析 |
| TOTALQTD() | 季初至今累计 | QTD分析 |
| DATEADD() | 日期偏移 | 环比分析 |
| PARALLELPERIOD() | 平行期间 | 期间对比 |
| DATESINPERIOD() | 日期范围 | 滚动计算 |

## 三、同比分析

### 什么是同比?

**同比** = 与去年同期对比

**公式**:
```
同比增长率 = (本期 - 去年同期) / 去年同期
```

---

### 实现: 去年同期销售额

```dax
去年同期销售额 =
CALCULATE(
    SUM('销售事实表'[金额]),
    SAMEPERIODLASTYEAR('日期维度表'[日期])
)
```

**前提条件**:
- 必须有日期维度表
- 日期维度表必须标记为"日期表"

---

### 如何标记日期表?

**步骤 1**: 右键点击"日期维度表"

**步骤 2**: 选择"标记为日期表"

**步骤 3**: 选择日期列: "日期"

---

### 实现: 同比增长率

```dax
同比增长率 =
DIVIDE(
    SUM('销售事实表'[金额]) - [去年同期销售额],
    [去年同期销售额]
)
```

**格式设置**:
- 点击度量值
- 开始 → % 按钮
- 设置为百分比格式

---

### 验证

创建一个表格:
- 月份
- 销售额
- 去年同期销售额
- 同比增长率

**注意**: 我们的数据只有 2024 年,所以去年同期是空值。实际项目中会有多年数据。

## 四、环比分析

### 什么是环比?

**环比** = 与上一个周期对比

**公式**:
```
环比增长率 = (本期 - 上期) / 上期
```

---

### 实现: 上月销售额

```dax
上月销售额 =
CALCULATE(
    SUM('销售事实表'[金额]),
    DATEADD('日期维度表'[日期], -1, MONTH)
)
```

**解释**:
- `DATEADD('日期维度表'[日期], -1, MONTH)` = 日期减 1 个月

---

### 实现: 环比增长率

```dax
环比增长率 =
DIVIDE(
    SUM('销售事实表'[金额]) - [上月销售额],
    [上月销售额]
)
```

---

### 累计计算

**年初至今累计**:
```dax
年初至今累计 =
TOTALYTD(
    SUM('销售事实表'[金额]),
    '日期维度表'[日期]
)
```

**月初至今累计**:
```dax
月初至今累计 =
TOTALMTD(
    SUM('销售事实表'[金额]),
    '日期维度表'[日期]
)
```

## 五、迭代函数

### 什么是迭代函数?

**迭代函数** = 逐行计算,然后聚合

**普通函数**: 一次性计算
```dax
SUM('表'[金额])  // 直接求和
```

**迭代函数**: 逐行计算后再聚合
```dax
SUMX('表', [金额] * [数量])  // 每行先计算,再求和
```

---

### 常用迭代函数

| 函数 | 用途 |
|------|------|
| SUMX() | 逐行计算后求和 |
| AVERAGEX() | 逐行计算后平均 |
| MAXX() | 逐行计算后最大值 |
| MINX() | 逐行计算后最小值 |
| COUNTX() | 逐行计算后计数 |

---

### 语法

```dax
SUMX(表, 表达式)
```

**参数**:
- 表: 要遍历的表
- 表达式: 每行要计算的表达式

---

### 实例 1: 计算总收入

假设销售表有"数量"和"单价"两列,但没有"金额"列。

**计算金额**:
```dax
总销售额 = SUMX('销售事实表', [数量] * [单价])
```

**解释**:
- 遍历销售表的每一行
- 每行计算: 数量 × 单价
- 把所有行的结果求和

---

### 实例 2: 计算利润

```dax
总利润 =
SUMX(
    '销售事实表',
    [金额] - RELATED('产品维度表'[成本价]) * [数量]
)
```

**解释**:
- 遍历销售表的每一行
- 每行计算: 金额 - 成本价 × 数量 = 利润
- 把所有利润求和

---

## 六、排名函数 RANKX

### 基本用法

```dax
排名 = RANKX(所有值, 当前值, , 排序方式)
```

**参数**:
- 所有值: 用于排名的所有值范围
- 当前值: 当前要排名的值
- 排序方式: DESC(降序) 或 ASC(升序)

---

### 实例: 产品销售排名

```dax
产品销售排名 =
RANKX(
    ALL('产品维度表'),       // 所有产品
    CALCULATE(SUM('销售事实表'[金额])),  // 当前产品销售额
    ,
    DESC                     // 降序(销售额大的排前面)
)
```

---

### 验证

创建一个表格:
- 产品名称
- 销售额
- 产品销售排名

你会看到:
```
产品名称        销售额    排名
iPhone 15 Pro  59990    1
MacBook Air    27993    2
iPad Air       14391    3
...
```

---

### 避免相同排名的问题

如果有两个产品销售额相同,排名也会相同。

**解决**: 添加辅助排序列
```dax
产品销售排名 =
RANKX(
    ALL('产品维度表'),
    CALCULATE(SUM('销售事实表'[金额])) + RANKX(ALL('产品维度表'), [产品ID], , ASC) / 1000,
    ,
    DESC
)
```

---

## 七、TOPN 函数

### 基本用法

```dax
TOPN(数量, 表, 排序字段, 排序方式)
```

---

### 实例: 前 3 名产品销售额

```dax
前3名产品销售额 =
CALCULATE(
    SUM('销售事实表'[金额]),
    TOPN(3, ALL('产品维度表'), CALCULATE(SUM('销售事实表'[金额])), DESC)
)
```

---

### 实际应用

创建一个卡片图,显示"前3名产品销售额"。

## 八、FILTER 函数进阶

### 基本用法

```dax
FILTER(表, 条件)
```

---

### 实例 1: 高价值订单

**目标**: 统计金额大于 5000 的订单数量

```dax
高价值订单数 =
COUNTROWS(
    FILTER(
        '销售事实表',
        '销售事实表'[金额] > 5000
    )
)
```

---

### 实例 2: VIP客户数量

**目标**: 统计总消费超过 10000 的客户数量

```dax
VIP客户数 =
COUNTROWS(
    FILTER(
        ALL('客户维度表'),
        CALCULATE(SUM('销售事实表'[金额])) > 10000
    )
)
```

**解释**:
- `ALL('客户维度表')` = 所有客户(不受筛选影响)
- `CALCULATE(SUM(...))` = 每个客户的总消费
- `FILTER(..., 条件)` = 筛选消费 > 10000 的客户
- `COUNTROWS()` = 统计数量

## 九、变量 VAR

### 为什么使用变量?

**好处**:
1. 代码更清晰
2. 性能更好(计算一次,多次使用)
3. 易于调试

---

### 语法

```dax
度量值 =
VAR 变量1 = 表达式1
VAR 变量2 = 表达式2
RETURN
    最终表达式
```

---

### 实例: 销售额占比(使用变量)

```dax
销售额占比 =
VAR 当前销售额 = SUM('销售事实表'[金额])
VAR 总销售额 = CALCULATE(SUM('销售事实表'[金额]), ALL('产品维度表'))
RETURN
    DIVIDE(当前销售额, 总销售额)
```

---

### 实例: 复杂计算(使用变量)

**目标**: 计算销售额增长率,如果去年同期为空则显示"无数据"

```dax
同比增长率(带判断) =
VAR 本期销售额 = SUM('销售事实表'[金额])
VAR 去年同期销售额 = CALCULATE(SUM('销售事实表'[金额]), SAMEPERIODLASTYEAR('日期维度表'[日期]))
RETURN
    IF(
        去年同期销售额 = BLANK(),
        BLANK(),
        DIVIDE(本期销售额 - 去年同期销售额, 去年同期销售额)
    )
```

## 十一、常见问题

### Q1: 时间智能函数返回空值?

**原因**: 日期表没有标记

**解决**:
1. 右键日期维度表
2. 标记为日期表
3. 选择日期列

---

### Q2: RANKX 排名全是 1?

**原因**: 没有使用 ALL 清除筛选

**解决**:
```dax
RANKX(ALL('产品维度表'), ...)
```

---

### Q3: 迭代函数计算结果不对?

**原因**: 筛选上下文没理解

**解决**:
- 检查表的范围
- 使用 ALL 或 ALLEXCEPT 控制筛选
