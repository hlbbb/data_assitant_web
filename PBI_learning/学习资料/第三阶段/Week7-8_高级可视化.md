## 一、高级图表类型

### 1. 散点图和气泡图

**用途**: 显示两个变量的关系

**场景**: 产品价格 vs 销量

**操作**:
1. 点击"散点图"
2. X轴: 单价
3. Y轴: 数量
4. 图例: 产品名称

**气泡图**: 在散点图基础上,用气泡大小表示第三个变量(如销售额)

---

### 2. 瀑布图

**用途**: 显示累计变化过程

**场景**: 月度销售额变化

**操作**:
1. 点击"瀑布图"
2. 类别: 月份
3. Y轴: 销售额

**效果**:
```
一月 ████████ 30000
二月 ███ 10000 (增长)
三月 ██ 8000 (下降)
...
总计 ████████ 48000
```

---

### 3. 漏斗图

**用途**: 显示流程转化

**场景**: 销售漏斗(浏览 → 加购 → 下单 → 支付)

**操作**:
1. 点击"漏斗图"
2. 类别: 流程阶段
3. 值: 数量

**效果**:
```
浏览 ████████████ 1000
加购 ████████     600
下单 ██████       400
支付 ████         200
```

---

### 4. 树状图

**用途**: 层级数据占比

**场景**: 产品类别 → 产品销售额

**操作**:
1. 点击"树状图"
2. 组: 产品类别
3. 详细信息: 产品名称
4. 值: 销售额

**效果**:
```
┌─────────┬─────────┐
│  手机   │  电脑   │
│ (iPhone)│ (Mac)   │
├─────────┼─────────┤
│  配件   │  平板   │
└─────────┴─────────┘
```

---

### 5. 旭日图

**用途**: 多层级占比(类似多层饼图)

**场景**: 地区 → 城市 → 销售额

**操作**:
1. 点击"旭日图"
2. 层级: 地区, 城市
3. 值: 销售额

---

### 6. 地图

**用途**: 地理数据可视化

**场景**: 各城市销售额

**操作**:
1. 点击"地图"
2. 位置: 城市 或 省份
3. 大小: 销售额

**注意**: 需要正确识别地理字段(右键字段 → 数据类别 → 省/市)

---

### 7. KPI 图

**用途**: 显示关键指标和目标对比

**场景**: 销售额 vs 目标

**操作**:
1. 点击"KPI"
2. 指标: 销售额
3. 目标: 目标销售额(需要先创建目标度量值)
4. 趋势轴: 月份

**效果**:
```
销售额: 147960
目标:   150000
状态:   接近目标(黄色)
```

---

### 8. 仪表盘图

**用途**: 显示进度或完成率

**场景**: 销售目标完成率

**操作**:
1. 点击"仪表盘"
2. 值: 完成率
3. 最小值: 0
4. 最大值: 1 或 100

## 二、自定义视觉对象

### 什么是自定义视觉对象?

Power BI 自带的图表不够用?可以从 AppSource 导入第三方图表。

---

### 如何导入?

**步骤 1**: 点击可视化区域右侧的"..."(更多选项)

**步骤 2**: 选择"从 AppSource 导入"

**步骤 3**: 搜索需要的图表

**步骤 4**: 点击"添加"

---

### 推荐自定义图表

#### 1. Zebra BI Tables

**用途**: 增强表格,支持小计、瀑布效果

**特点**:
- 自动计算小计
- 支持条件格式
- 更美观的表格

---

#### 2. Bullet Chart by OKViz

**用途**: 子弹图(对比实际值和目标值)

**场景**: 销售额 vs 目标 vs 去年同期

---

#### 3. Sparkline by OKViz

**用途**: 在表格中嵌入迷你图

**场景**: 表格中显示趋势线

---

#### 4. Synoptic Panel

**用途**: 自定义图形可视化(如商场平面图)

**场景**: 商场各区域销售热力图

---

### 使用自定义图表

导入后,自定义图表会出现在可视化区域,和普通图表一样使用。

---

## 三、条件格式

### 什么是条件格式?

**条件格式** = 根据数据自动设置颜色、图标

**场景**:
- 销售额高的显示绿色,低的显示红色
- 增长显示向上箭头,下降显示向下箭头

---

### 数据条

**步骤 1**: 选择表格或矩阵

**步骤 2**: 格式 → 特定列 → 条件格式 → 数据条

**步骤 3**: 设置:
- 最小值: 最低值,红色
- 最大值: 最高值,绿色

**效果**:
```
销售额
██████████ 59990 (iPhone)
██████     27993 (MacBook)
████       14391 (iPad)
```

---

### 图标集

**步骤 1**: 格式 → 特定列 → 条件格式 → 图标

**步骤 2**: 设置规则:
- >= 10000: 绿色向上箭头
- >= 5000: 黄色横箭头
- < 5000: 红色向下箭头

**效果**:
```
销售额
↑ 59990
↑ 27993
→ 14391
↓ 998
```

---

### 按值设置颜色

**步骤 1**: 格式 → 特定列 → 条件格式 → 字体颜色 或 背景色

**步骤 2**: 设置规则:
- 如果值 >= 10000,颜色为绿色
- 如果值 >= 5000,颜色为黄色
- 否则,颜色为红色

---

## 四、工具提示页

### 什么是工具提示页?

**工具提示页** = 鼠标悬停时显示的详细报告页

**场景**: 柱状图显示销售额,悬停时显示该产品的详细信息

---

### 创建工具提示页

**步骤 1**: 新建页面,命名为"产品详情提示"

**步骤 2**: 设计工具提示内容:
- 产品名称
- 销售额
- 订单数量
- 客户分布饼图

**步骤 3**: 设置页面大小:
- 格式 → 页面大小 → 工具提示

**步骤 4**: 在主页面设置工具提示:
- 选择柱状图
- 格式 → 工具提示 → 页面
- 选择"产品详情提示"

**效果**: 鼠标悬停在柱子上,显示详细信息。

## 五、小多图(Small Multiples)

### 什么是小多图?

**小多图** = 把一个图表拆分成多个小图表

**场景**: 各地区的月度销售趋势(每个地区一个小折线图)

---

### 操作

**步骤 1**: 创建折线图

**步骤 2**: 格式 → 小多图 → 开

**步骤 3**: 选择分组字段: 地区

**效果**:
```
华北区      华东区      华南区
📈📈📈     📈📈📈     📈📈📈
```

## 七、常见问题

### Q1: 地图显示不正确?

**原因**: 地理字段没有正确识别

**解决**:
- 右键字段 → 数据类别 → 选择正确的类别(省/市/国家)

---

### Q2: 自定义图表加载失败?

**原因**: 网络问题或图表不兼容

**解决**:
- 检查网络连接
- 更新 Power BI Desktop
- 尝试其他图表

---

### Q3: 条件格式不生效?

**原因**: 字段类型不对

**解决**:
- 确保是数值字段
- 检查规则设置
