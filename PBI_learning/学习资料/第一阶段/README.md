## 学习目标

掌握 Power BI 的基本操作,能够独立完成简单的数据分析报告。

完成本阶段后,你应该能够:
- [ ] 独立导入数据并进行基础清洗
- [ ] 创建基础可视化图表
- [ ] 理解关系模型概念
- [ ] 编写简单的 DAX 度量值
- [ ] 完成一个简单的销售分析仪表板
