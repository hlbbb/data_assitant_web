## 一、可视化是什么?

**可视化** = 把数据变成图表。

**为什么要可视化?**

给你看两张对比:

**表格形式**:
```
地区      销售额
华北区    65980
华东区    45980
华南区    35980
```

**图表形式**:
```
柱状图:
华北区 ████████████ 65980
华东区 ████████     45980
华南区 ██████       35980
```

哪个更容易看出差距?当然是图表!

---

## 二、Power BI 的图表类型

Power BI 有很多图表,我们先学最常用的:

### 基础图表

| 图表类型 | 用途 | 什么时候用 |
|----------|------|------------|
| 柱状图 | 比较数据大小 | 比如各产品销售额 |
| 条形图 | 同柱状图(横向) | 类别名称很长时 |
| 折线图 | 显示趋势变化 | 比如每月销售趋势 |
| 饼图 | 显示占比 | 比如产品类别占比 |
| 环形图 | 同饼图(中间空) | 更现代美观 |
| 表格 | 显示详细数据 | 需要看具体数值 |
| 矩阵 | 交叉表格 | 比如地区×产品 |
| 卡片图 | 显示单个数字 | 比如总销售额 |

## 三、创建第一个图表

### 步骤 1: 选择图表类型

位置: 右侧"可视化"区域

点击"柱状图"图标:
```
┌──┐
│  │
│  │
│  │
└──┘
```

画布会出现一个空的柱状图框。

---

### 步骤 2: 添加字段

**目标**: 显示各地区的销售额

**操作**:

1. 从左侧字段区找到"销售事实表"
2. 找到"金额"字段
3. 把"金额"拖到右侧可视化区域的"Y轴"

**或者更简单的方法**:

直接把"金额"字段拖到画布上的图表框里!

---

### 步骤 3: 添加类别

**目标**: 按地区显示销售额

**操作**:

问题: 销售事实表里只有"地区ID"(R001, R002...),没有地区名称。

我们需要从地区维度表获取名称。

**方法 1: 使用地区维度表**

1. 找到"地区维度表" → "地区名称"
2. 拖到可视化区域的"X轴"

图表会自动显示三个地区的销售额!

**方法 2: 使用员工表关联地区**

如果关系还没建立,可能看不到地区名称。
没关系,下一节课我们专门学关系模型。

## 四、常用图表实操

### 1. 卡片图: 显示总销售额

**用途**: 显示一个关键数字

**操作**:
1. 点击"卡片图"图标
2. 把"金额"拖进去

你会看到一个大数字: **147960**

这是所有订单的总销售额。

---

### 2. 柱状图: 各产品销售额

**操作**:
1. 点击"柱状图"图标
2. X轴: "产品维度表" → "产品名称"
3. Y轴: "销售事实表" → "金额"

你会看到:
```
iPhone 15 Pro ████████████
MacBook Air   ████████
iPad Air      ██████
...
```

---

### 3. 饼图: 产品类别占比

**操作**:
1. 点击"饼图"图标
2. 把"产品类别"拖进去(作为类别)
3. 把"金额"拖进去(作为值)

你会看到产品类别(手机、电脑、配件)的占比。

---

### 4. 折线图: 月度销售趋势

**问题**: 我们的日期维度表只有 Q1 数据,所以只能看到 1-3 月。

**操作**:
1. 点击"折线图"图标
2. X轴: "日期维度表" → "月份名称"或"月份"
3. Y轴: "销售事实表" → "金额"

你会看到 1月、2月、3月的销售趋势。

---

### 5. 表格: 详细订单数据

**操作**:
1. 点击"表格"图标
2. 把需要的字段都拖进去:
   - 订单ID
   - 订单日期
   - 产品名称
   - 客户姓名
   - 金额

你会看到所有订单的详细信息。

## 五、图表格式设置

创建图表后,你可以美化它。

### 位置

右侧可视化区域的第二个图标: 🖌️(格式)

---

### 常用设置

#### 1. 标题

**操作**:
- 格式 → 标题 → 开
- 标题文本: 输入"各地区销售额"
- 字体颜色: 选择颜色
- 字体大小: 调整大小

#### 2. 数据标签

**操作**:
- 格式 → 数据标签 → 开
- 显示每个柱子上的具体数字

#### 3. 颜色

**操作**:
- 格式 → 数据颜色
- 可以设置每个柱子的颜色
- 或者统一设置颜色

#### 4. 坐标轴

**操作**:
- 格式 → X轴 / Y轴
- 可以设置坐标轴的颜色、字体大小

### 目标

创建一个完整的销售分析仪表板,包含:
1. 总销售额卡片
2. 各地区销售额柱状图

---

### 步骤 1: 新建页面

如果你只有一个空白页面,可以直接使用。
或者点击底部的"+ 新建页面"。

---

### 步骤 2: 创建总销售额卡片

1. 点击"卡片图"
2. 添加"金额"字段
3. 格式设置:
   - 标题: "总销售额"

1. 点击"柱状图"
2. X轴: 地区名称
3. Y轴: 金额
4. 格式设置:
   - 标题: "各地区销售额"
   - 数据标签: 开
   - 颜色: 使用不同颜色

位置: 放在右上角

---

### 步骤 4: 创建各产品销售额条形图

1. 点击"条形图"(横向柱状图)
2. X轴: 产品名称
3. Y轴: 金额
4. 格式设置:
   - 标题: "各产品销售额"

位置: 放在左中位置

---

### 步骤 5: 创建月度销售趋势折线图

1. 点击"折线图"
2. X轴: 月份名称
3. Y轴: 金额
4. 格式设置:
   - 标题: "月度销售趋势"

位置: 放在右中位置

---

### 步骤 6: 创建产品类别占比饼图

1. 点击"饼图"
2. 类别: 产品类别
3. 值: 金额
4. 格式设置:
   - 标题: "产品类别占比"
   - 数据标签: 开

位置: 放在左下角

---

### 步骤 7: 创建订单明细表格

1. 点击"表格"
2. 添加字段:
   - 订单ID
   - 订单日期
   - 产品名称
   - 客户姓名
   - 金额
3. 格式设置:
   - 标题: "订单明细"

位置: 放在右下角

## 七、图表交互

Power BI 的图表会自动交互!

### 尝试一下

1. 点击柱状图的"华北区"
2. 你会发现其他图表也变化了!
   - 条形图只显示华北区的产品
   - 饼图只显示华北区的类别
   - 折线图只显示华北区的趋势
   - 表格只显示华北区的订单

这就是 Power BI 的**交互筛选**!

### 取消筛选

点击柱状图的空白区域,或点击右上角的"清除筛选"图标。

## 九、常见问题

**Q1: 图表看不到数据?**

可能原因:
- 字段没拖进去 → 检查可视化区域
- 数据类型错误 → 回 Power Query 检查
- 关系没建立 → 下一节课会解决

**Q2: 图表显示的数值不对?**

可能原因:
- Power BI 默认会"求和"
- 如果想看"平均值",点击字段右侧的小箭头 → 选择"平均值"

**Q3: 图表太小/太大?**

解决:
- 点击图表边框拖拽调整大小
- 点击图表标题拖拽调整位置
