## 一、什么是 Power Query?

Power Query 是 Power BI 的**数据清洗工具**。

**为什么需要清洗数据?**

想象你拿到一份销售数据:
- 有些列名很乱(比如"col_1"、"字段a")
- 有些数据类型错了(日期显示成文本)
- 有空行或重复数据
- 数据格式不一致

这些"脏数据"会影响分析结果。Power Query 就是帮你把脏数据洗干净。

**方法 1**: 从开始菜单

### Power Query 界面

```
┌─────────────────────────────────────────┐
│  功能区: 开始、转换、添加列、视图       │
├─────────┬───────────────────────────────┤
```

## 四、基础清洗操作

让我们对销售事实表进行清洗。

### 操作 1: 检查数据类型

**为什么要检查?**
- 日期列应该是"日期"类型
- 金额列应该是"数字"类型
- 如果类型错误,后续计算会出错

**如何查看?**
看数据预览区域的列标题,每个列名前面有小图标:
- `📅` = 日期类型
- `123` = 数字类型
- `ABC` = 文本类型

**如何修改?**

假设"订单日期"列显示为文本类型(ABC图标):

1. 点击"订单日期"列
2. 开始 → 数据类型 → 日期
3. 系统会自动转换

**检查销售事实表的数据类型**:
| 列名 | 应该是 | 检查是否正确 |
|------|--------|--------------|
| 订单ID | 文本 | ✓ |
| 订单日期 | 日期 | ✓ |
| 产品ID | 文本 | ✓ |
| 客户ID | 文本 | ✓ |
| 员工ID | 文本 | ✓ |
| 地区ID | 文本 | ✓ |
| 数量 | 数字 | ✓ |
| 单价 | 数字 | ✓ |
| 金额 | 数字 | ✓ |
| 支付方式 | 文本 | ✓ |

---

### 操作 2: 删除不需要的列

假设我们的分析不需要"支付方式"列:

1. 点击"支付方式"列
2. 开始 → 删除列

**实际操作**:
我们暂时保留所有列,练习即可。

---

### 操作 3: 重命名列

假设某列名字不清楚,想改个更易懂的名字:

1. 双击列名(比如"数量")
2. 输入新名字(比如"购买数量")
3. 按 Enter 确认

**实际操作**:
我们的列名已经很清晰,暂不修改。

---

### 操作 4: 筛选行

假设想只看金额大于 5000 的订单:

1. 点击"金额"列的小箭头
2. 选择"数字筛选器" → "大于"
3. 输入 5000
4. 点击确定

**实际操作**:
我们暂时保留所有数据,练习即可。

---

### 操作 5: 处理缺失值

假设某列有空值:

**方法 1: 删除空值行**
- 点击列的小箭头 → 取消勾选"(null)"

**方法 2: 替换空值**
- 转换 → 替换值
- 查找值: null
- 替换为: 0 或其他值

**检查我们的数据**:
没有空值,数据质量良好。

---

### 操作 6: 添加计算列

假设想添加一个"利润"列(金额 - 成本):

**注意**: 这个操作需要从产品表获取成本价,我们后续再学。

**简单示例**: 添加"年份"列

1. 添加列 → 从日期 → 年
2. 系统会根据"订单日期"自动生成"年份"列

## 五、步骤的重要性

**Power Query 的核心**: 每一步操作都会被记录。

**举个例子**:

你做了 3 步操作:
1. 删除"支付方式"列
2. 重命名"数量"为"购买数量"
3. 筛选金额 > 5000

右侧步骤区会显示:
```
步骤1: 已删除列
步骤2: 已重命名列
步骤3: 已筛选行
```

**好处**:
- 可以随时撤销某一步(点击步骤前的×)
- 可以修改某一步的参数
- 数据刷新时会自动重复这些步骤

## 六、保存和关闭

### 如何保存清洗结果?

1. 点击左上角"关闭并应用"
2. Power Query 会关闭
3. 数据加载到 Power BI 模型中

### 如何再次编辑?

1. 开始 → 转换数据
2. 重新进入 Power Query

## 八、常见问题

**Q1: 数据类型转换失败?**

原因: 数据中有非法值
解决:
- 先筛选查看异常值
- 修复或删除异常数据
- 再转换类型

**Q2: Power Query 操作后看不到原数据?**

不用担心! 步骤只是"视图",原数据没变。
- 点击步骤区的第一个步骤
- 就能看到原始数据

**Q3: 如何撤销所有操作?**

- 点击步骤区的第一个步骤"源"
- 后面的所有步骤都会撤销
