## 一、Power BI 是什么?

Power BI 是微软推出的**商业智能工具**,简单说就是帮你把数据变成图表的工具。

**举个例子**:
- 你手上有 50 条销售订单数据(Excel表格)
- 你想看哪个产品卖得最好
- 你想看每个月的销售趋势
- 你想看哪个地区销售额最高

用 Excel 你可能要手动做透视表、画图表。用 Power BI,你只需要拖拖拽拽,几分钟就能做出专业的仪表板。

---

## 二、Power BI 的优势

| 对比项 | Excel | Power BI |
|--------|-------|----------|
| 数据量 | 几万行就卡 | 百万行不卡 |
| 图表类型 | 基础图表 | 丰富的可视化 |
| 交互性 | 静态表格 | 动态交互 |
| 刷新数据 | 手动更新 | 自动刷新 |
| 分享 | 发送文件 | 在线查看 |

**总结**: 数据量小用 Excel,数据量大、需要经常更新、多人查看,用 Power BI。

---

## 三、Power BI 三个组件

```
Power BI Desktop (桌面端)
    ↓ 创建报告
Power BI Service (网页端)
    ↓ 发布分享
Power BI Mobile (手机端)
    ↓ 随时查看
```

**学习顺序**:
1. 先学 Desktop (我们主要学这个)
2. 再学 Service (发布分享)
3. Mobile 自己探索 (就是看报告)

## 四、安装 Power BI Desktop

### 步骤 1: 下载

打开微软官网下载页面:
```
https://www.microsoft.com/zh-cn/download/details.aspx?id=58494
```

或者直接搜索: "Power BI Desktop 下载"

### 步骤 2: 安装

1. 双击下载的 `.exe` 文件
2. 点击"下一步"直到完成
3. 安装完成后桌面会出现 Power BI Desktop 图标

### 步骤 3: 注册账户

1. 打开 Power BI Desktop
2. 点击右上角"登录"
3. 使用公司邮箱或微软账号注册

**注意**: 个人学习可以使用免费版,功能完全够用。

## 五、认识界面

打开 Power BI Desktop,你会看到这样的界面:

```
┌─────────────────────────────────────────┐
│  菜单栏: 文件、开始、插入、建模...       │
├─────────────────────────────────────────┤
│  功能区: 各种操作按钮                    │
├─────────┬───────────────────┬───────────┤
│         │                   │           │
│ 字段区  │    画布区域       │  可视化区 │
│ (左侧)  │   (中间)          │  (右侧)   │
│         │                   │           │
│ 表列表  │   放图表的地方    │  选图表   │
│ 字段    │                   │  设格式   │
│         │                   │           │
├─────────┴───────────────────┴───────────┤
│  筛选区: 筛选数据                        │
└─────────────────────────────────────────┘
```

**三个核心区域**:

1. **左侧 - 字段区**
   - 显示导入的表
   - 显示表的字段
   - 把字段拖到图表

2. **中间 - 画布区**
   - 放置图表的地方
   - 可以有多页

3. **右侧 - 可视化区**
   - 选择图表类型
   - 设置图表格式

## 六、第一个操作: 导入数据

让我们导入之前准备好的销售数据。

### 步骤 1: 打开 Power BI Desktop

### 步骤 2: 点击"获取数据"

位置: 开始菜单 → 获取数据 → 文本/CSV

### 步骤 3: 选择文件

找到数据源文件夹,选择: `销售事实表.csv`

### 步骤 4: 预览数据

你会看到一个预览窗口:
- 显示前几行数据
- 检查数据是否正确

### 步骤 5: 点击"加载"

数据就导入成功了!

## 八、常见问题

**Q1: 安装失败怎么办?**
- 检查是否是 Windows 10 或以上系统
- 关闭杀毒软件重试
- 以管理员身份运行安装程序

**Q2: 没有邮箱怎么注册?**
- 可以注册一个微软邮箱(outlook.com)
- 或者使用公司邮箱

**Q3: 免费版够用吗?**
- 学习阶段完全够用
- 主要限制: 无法发布到网页端
- 本地创建报告无限制
