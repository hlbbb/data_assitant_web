## 一、什么是 DAX?

**DAX** = Data Analysis Expressions(数据分析表达式)

简单说: **DAX 是 Power BI 的计算语言**

**为什么需要 DAX?**

比如你想计算:
- 利润 = 销售额 - 成本
- 占比 = 某产品销售额 / 总销售额
- 排名 = 某产品在所有产品中的位置

这些计算用简单的"求和"做不到,需要用 DAX。

---

## 二、计算列 vs 度量值

DAX 有两种写法:

### 1. 计算列(Calculated Column)

**特点**:
- 在表中新增一列
- 逐行计算
- 结果存储在表中
- 占用内存

**举例**:

在销售表新增"利润"列:
```
订单ID    金额    成本    利润(计算列)
ORD001    11998   9000    2998
ORD002    3999    3000    999
...
```

---

### 2. 度量值(Measure)

**特点**:
- 不在表中新增列
- 动态计算(根据筛选上下文)
- 结果不存储
- 不占用内存

**举例**:

创建"总销售额"度量值:
```dax
总销售额 = SUM('销售事实表'[金额])
```

当你选择不同筛选:
- 选择华北区 → 计算华北区销售额
- 选择iPhone → 计算iPhone销售额
- 动态变化,不存储

---

### 3. 应该用哪个?

**原则**:

| 场景 | 推荐使用 |
|------|----------|
| 需要逐行计算 | 计算列 |
| 需要动态计算 | 度量值 |
| 需要聚合计算(求和、平均) | 度量值 |
| 需要用于筛选或分组 | 计算列 |

**经验法则**:
- 90%的情况用度量值
- 只有必须逐行计算时才用计算列

## 四、基础 DAX 函数

### 1. 聚合函数

| 函数 | 用途 | 例子 |
|------|------|------|
| SUM() | 求和 | `SUM('表'[金额])` |
| AVERAGE() | 平均值 | `AVERAGE('表'[金额])` |
| COUNT() | 计数 | `COUNT('表'[订单ID])` |
| COUNTROWS() | 行数 | `COUNTROWS('表')` |
| MAX() | 最大值 | `MAX('表'[金额])` |
| MIN() | 最小值 | `MIN('表'[金额])` |

---

### 2. 数学函数

| 函数 | 用途 | 例子 |
|------|------|------|
| DIVIDE() | 安全除法 | `DIVIDE(10, 2)` = 5 |
| ABS() | 绝对值 | `ABS(-5)` = 5 |
| ROUND() | 四舍五入 | `ROUND(3.5, 0)` = 4 |

**DIVIDE vs "/"**:
- `10 / 0` → 报错
- `DIVIDE(10, 0)` → 返回空值(不报错)

**推荐**: 总是用 `DIVIDE()` 避免错误。

---

### 3. 文本函数

| 函数 | 用途 | 例子 |
|------|------|------|
| CONCATENATE() | 连接文本 | `CONCATENATE("张", "三")` = "张三" |
| LEFT() | 左边字符 | `LEFT("张三", 1)` = "张" |
| RIGHT() | 右边字符 | `RIGHT("张三", 1)` = "三" |
| LEN() | 文本长度 | `LEN("张三")` = 2 |
| UPPER() | 转大写 | `UPPER("abc")` = "ABC" |
| LOWER() | 转小写 | `LOWER("ABC")` = "abc" |

---

### 4. 逻辑函数

| 函数 | 用途 | 例子 |
|------|------|------|
| IF() | 条件判断 | `IF([金额]>1000, "大", "小")` |
| AND() | 逻辑与 | `AND([a]>0, [b]>0)` |
| OR() | 逻辑或 | `OR([a]>0, [b]>0)` |
| SWITCH() | 多条件 | `SWITCH(TRUE(), 条件1, 结果1, 条件2, 结果2, 默认)` |

---

### 5. 关系函数

| 函数 | 用途 | 例子 |
|------|------|------|
| RELATED() | 获取关联表的值 | `RELATED('产品表'[成本价])` |
| RELATEDTABLE() | 获取关联表的行 | `RELATEDTABLE('销售表')` |

## 六、实际操作: 创建计算列

### 计算列 1: 利润

**目标**: 每笔订单的利润 = 金额 - 成本

**问题**: 销售表没有成本价,成本价在产品表。

**解决**: 用 `RELATED()` 从产品表获取成本价。

**操作**:
1. 字段区 → 右键"销售事实表" → 新建列
2. 编辑栏输入:
```dax
利润 = '销售事实表'[金额] - RELATED('产品维度表'[成本价]) * '销售事实表'[数量]
```

**解释**:
- `'销售事实表'[金额]` = 销售金额
- `RELATED('产品维度表'[成本价])` = 从产品表获取成本价
- `* '销售事实表'[数量]` = 成本价 × 数量 = 总成本
- 金额 - 总成本 = 利润

**验证**:
- 销售表应该新增了"利润"列
- 可以在表格中看到每笔订单的利润

---

### 计算列 2: 年份

**目标**: 从订单日期提取年份

**操作**:
```dax
年份 = YEAR('销售事实表'[订单日期])
```

**验证**:
- 销售表新增"年份"列
- 所有值都是 2024

## 七、核心函数: CALCULATE()

### CALCULATE 是什么?

**CALCULATE** = 修改筛选上下文的函数

简单说: **可以在计算时添加或修改筛选条件**

---

### 基础用法

**语法**:
```dax
CALCULATE(表达式, 筛选条件1, 筛选条件2, ...)
```

---

### 实例 1: 计算iPhone销售额

**目标**: 只计算iPhone 15 Pro的销售额

**操作**:
```dax
iPhone销售额 = CALCULATE(
    SUM('销售事实表'[金额]),
    '产品维度表'[产品名称] = "iPhone 15 Pro"
)
```

**解释**:
- `SUM('销售事实表'[金额])` = 计算销售额
- `'产品维度表'[产品名称] = "iPhone 15 Pro"` = 只筛选iPhone

**验证**:
- 创建卡片图
- 应该显示 iPhone 的总销售额

---

### 实例 2: 计算华北区销售额

**目标**: 只计算华北区的销售额

**操作**:
```dax
华北区销售额 = CALCULATE(
    SUM('销售事实表'[金额]),
    '地区维度表'[地区名称] = "华北区"
)
```

---

### 实例 3: 计算占比

**目标**: 某产品销售额占总销售额的比例

**操作**:
```dax
销售额占比 = DIVIDE(
    SUM('销售事实表'[金额]),
    CALCULATE(SUM('销售事实表'[金额]), ALL('产品维度表'))
)
```

**解释**:
- `SUM('销售事实表'[金额])` = 当前筛选的销售额(比如iPhone)
- `CALCULATE(SUM(...), ALL('产品维度表'))` = 清除产品筛选,计算总销售额
- `DIVIDE()` = 计算占比

**验证**:
- 创建一个表格
- 显示产品名称和销售额占比
- 点击不同产品,占比会变化

---

## 八、核心函数: ALL()

### ALL 是什么?

**ALL** = 清除筛选

**用途**: 计算占比、总计等

---

### 用法 1: ALL(表)

清除整张表的筛选:
```dax
CALCULATE(SUM('销售事实表'[金额]), ALL('产品维度表'))
```

---

### 用法 2: ALL(字段)

清除某个字段的筛选:
```dax
CALCULATE(SUM('销售事实表'[金额]), ALL('产品维度表'[产品名称]))
```

---

### 用法 3: ALLEXCEPT(表, 字段)

清除筛选,但保留某个字段的筛选:
```dax
CALCULATE(SUM('销售事实表'[金额]), ALLEXCEPT('产品维度表', '产品维度表'[产品类别]))
```

**解释**: 清除产品表的所有筛选,但保留"产品类别"的筛选。

## 九、DAX 学习技巧

### 1. 从简单开始

## 十一、常见问题

### Q1: DAX 报错"找不到表"?

**原因**: 表名写错了

**解决**:
- 用单引号包围表名: `'销售事实表'`
- 表名要完全一致

---

### Q2: DAX 报错"找不到列"?

**原因**: 列名写错了

**解决**:
- 用方括号包围列名: `[金额]`
- 列名要完全一致

---

### Q3: 度量值显示的数值不对?

**原因**: 筛选上下文没理解

**解决**:
- 检查是否有其他筛选
- 尝试清除筛选看结果

---

### Q4: RELATED() 返回空值?

**原因**: 关系没建立或关系方向错误

**解决**:
- 检查关系是否存在
- 确保关系方向正确
