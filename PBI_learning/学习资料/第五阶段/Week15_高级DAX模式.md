## 一、移动平均

### 什么是移动平均?

**移动平均** = 最近 N 个周期的平均值

**用途**: 平滑数据波动,显示趋势

**场景**: 3 个月移动平均销售额

---

### 实现: 3 个月移动平均

```dax
3个月移动平均 =
AVERAGEX(
    DATESINPERIOD(
        '日期维度表'[日期],
        LASTDATE('日期维度表'[日期]),
        -3,
        MONTH
    ),
    CALCULATE(SUM('销售事实表'[金额]))
)
```

**解释**:
- `DATESINPERIOD()` = 获取最近 3 个月的日期范围
- `LASTDATE()` = 当前上下文的最后日期
- `AVERAGEX()` = 计算平均值

---

### 验证

创建折线图:
- X轴: 月份
- Y轴: 销售额, 3个月移动平均

你会看到移动平均线比原始数据更平滑。

## 二、ABC 分类(帕累托分析)

### 什么是 ABC 分类?

**ABC 分类** = 根据重要性将产品分为三类

- **A 类**: 前 80% 销售额的产品(最重要)
- **B 类**: 80%-95% 销售额的产品(次重要)
- **C 类**: 95%-100% 销售额的产品(不重要)

---

### 实现: 产品 ABC 分类

#### 步骤 1: 计算累计占比

```dax
累计销售额占比 =
VAR 当前产品销售额 = SUM('销售事实表'[金额])
VAR 所有产品销售额 = CALCULATE(SUM('销售事实表'[金额]), ALL('产品维度表'))
VAR 累计销售额 =
    CALCULATE(
        SUM('销售事实表'[金额]),
        FILTER(
            ALL('产品维度表'),
            CALCULATE(SUM('销售事实表'[金额])) >= 当前产品销售额
        )
    )
RETURN
    DIVIDE(累计销售额, 所有产品销售额)
```

---

#### 步骤 2: ABC 分类

```dax
ABC分类 =
VAR 累计占比 = [累计销售额占比]
RETURN
    SWITCH(
        TRUE(),
        累计占比 <= 0.8, "A",
        累计占比 <= 0.95, "B",
        "C"
    )
```

---

### 验证

- 产品名称
- 销售额
- 累计销售额占比
- ABC分类

按销售额降序排列,查看 ABC 分类是否正确。

## 三、客户留存分析

### 什么是留存分析?

**留存率** = 一段时间后仍然活跃的客户比例

**场景**: 1 月注册的客户,有多少在 2 月、3 月仍然购买?

---

### 实现: 客户留存率

#### 步骤 1: 新客户数

```dax
新客户数 =
VAR 当前月份 = MIN('日期维度表'[月份])
VAR 当前月份客户 =
    CALCULATETABLE(
        VALUES('销售事实表'[客户ID]),
        '日期维度表'[月份] = 当前月份
    )
VAR 之前月份客户 =
    CALCULATETABLE(
        VALUES('销售事实表'[客户ID]),
        '日期维度表'[月份] < 当前月份
    )
RETURN
    COUNTROWS(
        EXCEPT(当前月份客户, 之前月份客户)
    )
```

**解释**: 当前月份首次购买的客户数。

---

#### 步骤 2: 留存客户数

```dax
留存客户数(第N月) =
VAR 当前月份 = MIN('日期维度表'[月份])
VAR 目标月份 = 当前月份 + 1  // 第N月,这里N=1
VAR 当前月份新客户 =
    FILTER(
        VALUES('销售事实表'[客户ID]),
        CALCULATE(COUNTROWS('销售事实表'), '日期维度表'[月份] = 当前月份) > 0
        &&
        CALCULATE(COUNTROWS('销售事实表'), '日期维度表'[月份] < 当前月份) = 0
    )
RETURN
    CALCULATE(
        DISTINCTCOUNT('销售事实表'[客户ID]),
        '日期维度表'[月份] = 目标月份,
        当前月份新客户
    )
```

---

#### 步骤 3: 留存率

```dax
留存率 =
DIVIDE([留存客户数(第N月)], [新客户数])
```

## 四、新老客户分析

### 新客户 vs 老客户

```dax
新客户销售额 =
VAR 当前客户 = VALUES('销售事实表'[客户ID])
VAR 老客户 =
    FILTER(
        当前客户,
        CALCULATE(
            COUNTROWS('销售事实表'),
            DATEADD('日期维度表'[日期], -1, YEAR)
        ) > 0
    )
RETURN
    CALCULATE(
        SUM('销售事实表'[金额]),
        EXCEPT(当前客户, 老客户)
    )
```

```dax
老客户销售额 =
VAR 当前客户 = VALUES('销售事实表'[客户ID])
VAR 老客户 =
    FILTER(
        当前客户,
        CALCULATE(
            COUNTROWS('销售事实表'),
            DATEADD('日期维度表'[日期], -1, YEAR)
        ) > 0
    )
RETURN
    CALCULATE(
        SUM('销售事实表'[金额]),
        老客户
    )
```

## 五、购物篮分析(关联销售)

### 什么是购物篮分析?

**场景**: 买了 iPhone 的客户,还会买什么?

---

### 实现: 关联产品

```dax
买了iPhone的客户数 =
CALCULATE(
    DISTINCTCOUNT('销售事实表'[客户ID]),
    '产品维度表'[产品名称] = "iPhone 15 Pro"
)
```

```dax
买了iPhone又买了其他产品的客户数 =
VAR iPhone客户 =
    CALCULATETABLE(
        VALUES('销售事实表'[客户ID]),
        '产品维度表'[产品名称] = "iPhone 15 Pro"
    )
RETURN
    CALCULATE(
        DISTINCTCOUNT('销售事实表'[客户ID]),
        iPhone客户,
        '产品维度表'[产品名称] <> "iPhone 15 Pro"
    )
```

## 六、客户 RFM 分析

### 什么是 RFM?

- **R(Recency)**: 最近一次购买时间
- **F(Frequency)**: 购买频率
- **M(Monetary)**: 购买金额

---

### 实现 RFM 评分

#### R 评分

```dax
R评分 =
VAR 最近购买天数 = DATEDIFF(MAX('销售事实表'[订单日期]), TODAY(), DAY)
RETURN
    SWITCH(
        TRUE(),
        最近购买天数 <= 30, 5,
        最近购买天数 <= 60, 4,
        最近购买天数 <= 90, 3,
        最近购买天数 <= 180, 2,
        1
    )
```

---

#### F 评分

```dax
F评分 =
VAR 购买次数 = COUNTROWS('销售事实表')
RETURN
    SWITCH(
        TRUE(),
        购买次数 >= 10, 5,
        购买次数 >= 5, 4,
        购买次数 >= 3, 3,
        购买次数 >= 2, 2,
        1
    )
```

---

#### M 评分

```dax
M评分 =
VAR 消费金额 = SUM('销售事实表'[金额])
RETURN
    SWITCH(
        TRUE(),
        消费金额 >= 10000, 5,
        消费金额 >= 5000, 4,
        消费金额 >= 3000, 3,
        消费金额 >= 1000, 2,
        1
    )
```

---

#### RFM 总分

```dax
RFM总分 = [R评分] + [F评分] + [M评分]
```

## 八、常见问题

### Q1: 移动平均计算结果为空?

**原因**: 日期范围不足

**解决**: 确保有足够的历史数据

---

### Q2: ABC 分类不准确?

**原因**: 排序或累计计算错误

**解决**: 检查累计占比计算逻辑

---

### Q3: 留存分析很复杂?

**原因**: 需要理解时间上下文

**解决**: 分步骤调试,使用变量简化逻辑
