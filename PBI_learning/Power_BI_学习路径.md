**Day 11-14: DAX基础**
- 计算列 vs 度量值
- 基础函数:
```dax
SUM()           // 求和
AVERAGE()       // 平均值
COUNTROWS()     // 计数
CALCULATE()     // 修改筛选上下文
FILTER()        // 筛选表
ALL()           // 清除筛选
```

**实践**:
```dax
总销售额 = SUM('销售表'[金额])
平均订单金额 = AVERAGE('销售表'[金额])
销售订单数 = COUNTROWS('销售表')
占比 = DIVIDE([销售额], CALCULATE([销售额], ALL('产品表')))
```

### Week 5-6: DAX进阶

**时间智能函数**:
```dax
SAMEPERIODLASTYEAR()    // 去年同期
TOTALYTD()              // 年初至今累计
TOTALMTD()              // 月初至今累计
DATEADD()               // 日期偏移
DATESINPERIOD()         // 日期范围
```

**高级计算函数**:
```dax
SUMX()          // 迭代求和
AVERAGEX()      // 迭代平均
RANKX()         // 排名
TOPN()          // 前N名
RELATED()       // 关联数据
```

**实践**:
```dax
// 同比分析
去年同期销售额 = CALCULATE([销售额], SAMEPERIODLASTYEAR('日期表'[日期]))
同比增长率 = DIVIDE([销售额] - [去年同期销售额], [去年同期销售额])

// 环比分析
环比增长率 = DIVIDE(
    [销售额] - CALCULATE([销售额], DATEADD('日期表'[日期], -1, MONTH)),
    CALCULATE([销售额], DATEADD('日期表'[日期], -1, MONTH))
)

// 排名
产品销售排名 = RANKX(ALL('产品表'), [销售额], , DESC)
```

## 第五阶段:专家级应用(第15-16周)

### Week 15: 高级DAX模式

**常用模式**:
```dax
// 移动平均(3个月)
移动平均 =
AVERAGEX(
    DATESINPERIOD('日期表'[日期], LASTDATE('日期表'[日期]), -3, MONTH),
    [销售额]
)

// ABC分类
ABC分类 =
VAR 累计占比 =
CALCULATE(
    [累计销售额占比],
    FILTER(ALL('产品表'), [销售额] >= MAX('产品表'[销售额]))
)
RETURN
SWITCH(TRUE(),
    累计占比 <= 0.8, "A",
    累计占比 <= 0.95, "B",
    "C"
)

// 留存率
留存率 =
DIVIDE(
    CALCULATE([客户数], DATEADD('日期表'[日期], -1, MONTH)),
    CALCULATE([客户数], DATEADD('日期表'[日期], -2, MONTH))
)
```

**业务场景**:
- 客户留存分析
- 产品ABC分类
- 购物篮分析
- 新老客户分析

## 学习建议

**方法**:
- 理论+实践,每学一个概念立即动手
- 用真实项目串联知识点
- 不要跳过基础

**误区**:
- 只学可视化,忽视数据建模
- 不理解上下文就写DAX
- 过度使用计算列
- 忽视性能优化

**进阶路径**:
- 自定义视觉对象开发
- 数据工程(数据仓库、ETL)
- Azure数据服务
- Python/R集成
- PL-300认证考试
